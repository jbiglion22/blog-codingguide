# 수시 추가합격 커뮤니티 글 모음

블로그 글(수시 추가합격·예비번호 관련)을 쓸 때 수험생·학부모가 실제로 무엇을 궁금해하고 걱정하는지 참고하려고 모은 자료입니다.

## 무엇을 모았나
- 출처: 수험생 커뮤니티 오르비(orbi.kr)에서 검색어 '추합'으로 나온 글
- 저장한 것: 글 제목, 검색 결과에 보이는 미리보기(앞부분 150자 안팎), 작성 시각, 원문 주소
- 저장하지 않은 것: 본문 전체(경험담·질문과답변만 앞 600자), 작성자 닉네임·프로필
- 수집: 2026-11-27, 스크립트로 검색 결과 쪽을 차례로 읽음

## 어떻게 나눴나
- **학년도**: 11월~다음 해 10월에 쓴 글을 다음 해 학년도로 봄(예: 2025년 12월 글 → 2026학년도).
- **수시 추합 시기만**: 각 학년도의 전년 11월 20일 ~ 1월 10일 글만 남김. 2월(정시 추합)은 뺌.
- **정시 글 빼기**: 진학사·칸·점공·가나다군 같은 정시 모의지원 낱말만 있고 수시 낱말(예비·전화·학종·교과·논술 등)이 없는 글은 뺌.
- **학교**: 제목·미리보기에 나온 학교 이름(줄임말 포함: 설대·성대·냥대·외대·홍대 등)으로 파일을 나눔. 한 글에 여러 학교가 나오면 각 학교 폴더에 모두 넣고, 학교가 없으면 `학교미상/`.
- **태그**: 전화·몇 번까지·예비번호·등록·포기·불안 같은 유형을 낱말로 자동 표시.

## 주의
- 자동 분류라 학교·유형이 틀릴 수 있습니다(예: '중대'가 다른 뜻으로 쓰인 경우, 줄임말이 겹치는 경우).
- 커뮤니티 글은 개인 경험·추측이라 사실 근거로 쓰지 않습니다. 블로그에는 질문 유형을 참고하는 데만 쓰고, 문장·내용을 옮기지 않습니다.
- 2027학년도 파일은 수집한 날(2026-11-27)까지의 글만 있어 추합 시즌 전 글입니다.

## 다시 만들기
- 본문·댓글: `python -I 도구/수시추합_본문댓글수집.py 임시폴더/posts.json 임시폴더/pages.json`(bs4 필요, 이어 받기 가능) → 나누기 스크립트 세 번째 인자로 pages.json을 주면 경험담·질문과답변까지 만듦.
- `python -I 도구/수시추합_수집.py 임시폴더/posts.json` → `python -I 도구/수시추합_나누기.py 임시폴더/posts.json 자료실/수시추합데이터` (이 폴더 안의 학교 폴더와 요약 파일을 지우고 새로 만듦, README는 그대로). 원본 JSON은 저장소에 두지 않음.
- 2026-11-27 수집 결과: 글 5,579편(2024-11-20 ~ 2026-11-27) 중 수시 추합 시기 글 2025학년도 666편·2026학년도 815편·2027학년도 90편.

## 폴더 구조 (묶음 → 학교 → 학년도)
- `서울지역/학교이름/2026학년도.md` — 본교(본캠퍼스)가 서울에 있는 대학(예: `서울지역/고려대/2026학년도.md`)
- `특수학교/학교이름/…` — `네이버-코딩가이드-대학입시2027-연재.md`의 '특수대학 목록' 기준: 과학기술원(KAIST·UNIST·GIST·DGIST)·포스텍·사관학교·경찰대·한예종·교육대학·한국교원대. 서울교대도 여기에 들어감
- `그외지역/학교이름/…` — 그 밖의 대학(본교가 경기·인천인 단국대·가천대·가톨릭대·경기대·인하대·아주대 등 포함)
- `학교미상/` — 학교 이름이 나오지 않은 글
- `학교목록.md` — 묶음별로 학교마다 학년도별 글 수(숫자를 누르면 해당 파일)
- `학년도별_요약.md` — 학년도별 글 수와 질문 유형별 글 수
- 학교 폴더 안 `경험담.md` — 추가합격을 직접 겪은 이야기로 보이는 글(제목이 질문이 아니고, 1인칭·겪은 일·추합 낱말이 있으며 칼럼·분석·정시 글이 아닌 것, 본문 앞 600자와 의미 있는 댓글). 2년 치에서 30편 남짓으로 적음
- 학교 폴더 안 `질문과답변.md` — 질문 글 가운데 25자 이상의 내용 있는 댓글(짧은 응원·한 줄 답 제외)이 달린 것 약 500편. 댓글은 개인 의견이라 틀릴 수 있음
- 그 학년도에 글이 없으면 파일이 없음. 묶음 기준은 `도구/수시추합_나누기.py`의 SPECIAL·SEOUL 목록
