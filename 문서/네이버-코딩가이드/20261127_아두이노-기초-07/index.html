🤖 두이: 안녕! 나는 화면이 없어서 말을 못 했어. 오늘은 컴퓨터 화면을 빌려서 처음으로 말해 볼 거야!

[[ 이미지: 타이틀 (01-타이틀.png) ]]

'아두이노 기초' 연재 7편입니다.

아두이노에는 화면이 없어요. 그래서 무슨 생각을 하는지 알기 어렵죠.

오늘은 아두이노가 컴퓨터 화면에 글자를 보내게 해 볼 거예요.

 

이번 편에서 만들 것

오늘은 세 가지를 차례로 해 봐요.

• 아두이노가 인사 한 줄 보내기

• 글자를 한 줄로, 또는 줄을 바꿔 보내기

• 1초마다 숫자 세기

[[ 이미지: 이번 편에서 만들 것 (02-이번-편에서-만들-것.png) ]]

준비물: 아두이노 우노(이 연재는 우노 R3 기준), USB 케이블, 컴퓨터

이번에는 브레드보드도, 선도 필요 없어요. USB 케이블만 꽂으면 돼요.

 

시리얼 모니터는 무엇일까?

아두이노가 보낸 글자를 컴퓨터에서 보여 주는 창이에요.

이 창의 이름이 시리얼 모니터예요.

🧩 쉽게 이해하기 — 아두이노의 문자 메시지

• 아두이노는 휴대폰이 없는 친구예요.

• 대신 USB 케이블로 컴퓨터에 문자를 보내요.

• 우리는 컴퓨터 화면에서 그 문자를 읽어요.

• 한 줄 정리: 시리얼 모니터는 아두이노의 문자 메시지 창이에요!

 

첫째, 인사 한 줄 보내기

아래 코드를 IDE에 그대로 써 보세요.

void setup() {
  Serial.begin(9600);
  Serial.println("안녕! 나는 아두이노야.");
}

void loop() {
}

한 줄씩 볼까요?

• Serial.begin(9600); — 컴퓨터와 이야기할 준비를 해요.

• Serial.println("…"); — 따옴표 안의 글자를 컴퓨터로 보내요.

• loop() 안은 비어 있어요. 인사는 한 번만 하면 되거든요.

▶ 9600은 무슨 숫자일까?

글자를 주고받는 빠르기예요.

🧩 쉽게 이해하기 — 말하는 빠르기 맞추기

• 친구가 아주 빠르게 말하는데, 나는 천천히 듣는다고 해 봐요.

• 무슨 말인지 하나도 못 알아듣겠죠?

• 아두이노와 컴퓨터도 같은 빠르기로 맞춰야 해요.

• 한 줄 정리: 코드에 9600이라고 썼으면, 시리얼 모니터도 9600으로 맞춰요!

먼저 업로드 버튼(오른쪽 화살표)을 눌러 코드를 올려요.

그다음 IDE 오른쪽 위의 시리얼 모니터 버튼을 눌러요. 화면 아래쪽에 창이 열려요.

창 오른쪽에서 빠르기를 9600으로 골라요.

둘째, 한 줄로? 줄을 바꿔서?

글자를 보내는 말은 두 가지가 있어요.

• Serial.print — 글자만 보내요.

• Serial.println — 글자를 보내고 줄을 바꿔요.

끝에 붙은 ln은 '줄(line)'이라는 뜻이에요.

직접 비교해 봐요. 첫째 코드를 지우고 이 코드를 올려요.

void setup() {
  Serial.begin(9600);
  Serial.print("사과 ");
  Serial.print("바나나 ");
  Serial.println("포도");
  Serial.println("딸기");
}

void loop() {
}

이렇게 나와요.

[[ 이미지: print와 println (05-print와-println.png) ]]

사과·바나나·포도는 한 줄에 붙어 나왔어요. '포도'를 보낸 println이 줄을 바꿔서, 딸기는 다음 줄에 나왔어요.

🧩 쉽게 이해하기 — 엔터 키

• 공책에 글을 쓸 때 엔터를 누르면 다음 줄로 가죠?

• print는 엔터 없이 이어 쓰기예요.

• println은 다 쓰고 엔터를 누르는 거예요.

• 한 줄 정리: 줄을 바꾸고 싶으면 println!

 

셋째, 1초마다 숫자 세기

이번에는 아두이노가 숫자를 세게 해 봐요.

int count = 0;   // 숫자를 넣어 둘 기억 상자

void setup() {
  Serial.begin(9600);
}

void loop() {
  count = count + 1;          // 상자 속 숫자에 1 더하기
  Serial.print("숫자: ");
  Serial.println(count);      // 상자 속 숫자 보여 주기
  delay(1000);                // 1초 쉬기
}

한 줄씩 볼까요?

• count는 6편에서 배운 기억 상자예요. 처음엔 0이 들어 있어요.

• loop()가 한 번 돌 때마다 1씩 커져요.

• print로 '숫자: '를 쓰고, println으로 숫자를 쓴 뒤 줄을 바꿔요.

• delay(1000)으로 1초 쉬어요.

숫자에는 따옴표를 붙이지 않았어요. 따옴표가 없으면 상자 속 숫자를 보여 줘요.

이렇게 나와요.

[[ 이미지: 셋째 결과 (06-셋째-결과.png) ]]

1초마다 한 줄씩 늘어나요. 아두이노가 지금 몇까지 셌는지 화면으로 볼 수 있죠.

💡 두이의 꿀팁: 코드가 생각대로 안 될 때도 시리얼 모니터에 숫자를 찍어 봐. 내 속마음이 보여서 틀린 곳을 찾기 쉬워!

 

안 될 때 확인할 것

막히면 하나씩 살펴봐요.

• 이상한 글자가 나와요 → 창의 빠르기가 9600인지 보세요.

• 아무것도 안 나와요 → 코드에 Serial.begin(9600);이 있는지 보세요. 업로드가 끝났는지도요.

• 모든 글자가 한 줄에 붙어요 → print를 println으로 바꿔 보세요.

• 한글만 깨져요 → 따옴표 안을 영어로 바꿔 보세요. 예: "Hello"

👩‍🏫 학부모·선생님께

• 이 편은 부품 없이 보드와 USB 케이블만 씁니다. 다음 편부터 시리얼 모니터로 센서 값을 계속 확인하니, 창 여는 법과 9600 맞추기를 익혀 두면 좋습니다.

• 본문은 쉽게 줄여 썼습니다. 정확히는 이렇습니다.

• 9600은 시리얼 통신 속도(baud)입니다. 코드와 시리얼 모니터의 값이 같으면 다른 값(예: 115200)을 써도 됩니다.

• 시리얼 모니터에서 아두이노로 글자를 보내는 방법(Serial.read 등)도 있습니다. 이 편에서는 아두이노가 보내는 쪽만 다뤘습니다.

• int가 담을 수 있는 숫자의 크기는 보드마다 다릅니다. 우노 R3에서는 int가 32767까지라서, 아주 오래 켜 두면 그다음에 음수로 넘어갑니다(1초에 한 번 세면 9시간 넘게 걸려 수업 중에는 문제가 되지 않습니다). 우노 R4는 int가 훨씬 큰 수까지 담습니다.

• 한글이 잘 보이는지는 컴퓨터 환경에 따라 다를 수 있습니다.
