오늘은 폴더 속 파일 이름을 파이썬으로 한 번에 뽑아 봅니다. 개수까지 세어 줍니다.

 

결과부터 보기

코드를 실행하면 폴더 속 파일 이름이 줄줄이 나옵니다. 마지막 줄에는 모두 몇 개인지 나옵니다.

[[ 이미지: 결과 미리보기 (02-결과-미리보기.png) ]]

이 목록은 그대로 복사해 엑셀이나 메일에 붙일 수 있어요.

오늘 배우는 파일 목록 코드는 이름을 바꾸거나 지우지 않습니다. 보기만 해요.

다만 3단계에서는 연습용 빈 파일을 새로 만듭니다.

 

1단계: 이름 여러 개를 한 이름표에 담기

1편에서는 이름표(변수) 하나에 값 하나를 담았습니다.

파일은 여러 개입니다. 그래서 값을 여러 개 담는 방법이 필요해요.

IDLE에서 새 파일을 열고 아래를 입력한 뒤 F5를 눌러 보세요.

names = ["1월_매출.xlsx",
         "견적서_A사.pdf",
         "회의록.docx"]
print(names)
print(len(names))
print(names[0])
['1월_매출.xlsx', '견적서_A사.pdf', '회의록.docx']
3
1월_매출.xlsx

대괄호 [ ] 안에 쉼표로 값을 늘어놓은 것을 리스트라고 합니다.

[[ 이미지: 리스트는 칸 상자 (03-리스트는-칸-상자.png) ]]

▣ 리스트에서 알아 둘 세 가지

  • len(names)는 칸이 몇 개인지 셉니다. 여기서는 3이에요.
  • names[0]은 첫 번째 칸입니다.
  • 칸의 위치 번호(인덱스)는 1이 아니라 0부터 시작합니다. 세 칸이면 0, 1, 2예요.

괄호 안에서는 줄을 바꿔 써도 됩니다. 휴대폰에서 읽기 쉽게 한 줄에 하나씩 적었어요.

 

2단계: 하나씩 꺼내 보여 주기

print(names)는 리스트 전체를 대괄호와 따옴표까지 포함해 보여 줍니다. 보고서에 붙이기엔 불편하죠.

한 줄에 하나씩 보고 싶다면 for를 씁니다.

names = ["1월_매출.xlsx",
         "견적서_A사.pdf",
         "회의록.docx"]
for name in names:
    print(name)
print("끝")
1월_매출.xlsx
견적서_A사.pdf
회의록.docx
끝

for name in names:는 "names에서 하나씩 꺼내 name이라 부르고, 아래 일을 해라"라는 뜻입니다.

[[ 이미지: for 반복 흐름 (04-for-반복-흐름.png) ]]

▣ 들여쓰기가 '아래 일'의 범위입니다

  • 줄 끝의 쌍점(:)은 "여기부터 할 일이 나온다"는 표시예요.
  • 반복할 줄은 스페이스 4칸 들여 씁니다. IDLE에서는 쌍점 뒤에 엔터를 치면 다음 줄이 자동으로 들여쓰기됩니다.
  • print("끝")은 들여쓰지 않았습니다. 그래서 반복이 다 끝난 뒤 한 번만 나와요.

파이썬에서 들여쓰기는 꾸밈이 아니라 문법입니다. 칸 수가 틀리면 오류가 나요.

 

3단계: 연습용 파일 8개 만들기

이제 진짜 폴더에서 이름을 가져올 차례입니다.

회사 파일로 연습하지 않도록, 연습 파일을 코드로 만들어 둘게요.

아래 코드를 파이썬연습 폴더 안에 make_samples.py라는 이름으로 저장하고 F5를 누르세요.

from pathlib import Path

folder = Path(__file__).parent / "샘플"
folder.mkdir(exist_ok=True)

names = [
    "1월_매출.xlsx",
    "2월_매출.xlsx",
    "3월_매출.xlsx",
    "거래처_목록.xlsx",
    "견적서_A사.pdf",
    "견적서_B사.pdf",
    "회의록_1105.docx",
    "행사_사진.jpg",
]
for name in names:
    (folder / name).touch()

print("연습 파일을 만들었습니다.")

코드가 정상 실행되면 '연습 파일을 만들었습니다.'가 나옵니다. 파이썬연습 폴더 안에 샘플 폴더와 빈 파일 8개가 만들어져요.

앞에서 배운 리스트와 for가 그대로 들어 있죠? 리스트에 담긴 이름 8개를 for로 하나씩 꺼내 빈 파일을 만든 것입니다.

▣ 처음 보는 줄만 짧게

  • from pathlib import Path: 파일과 폴더를 다루는 도구를 꺼내 옵니다.
  • Path(__file__).parent: '이 코드 파일이 있는 폴더'를 뜻합니다. 그래서 코드 파일을 꼭 저장한 뒤 실행해야 해요.
  • / "샘플": 그 폴더 안의 '샘플' 폴더라는 뜻입니다. 나눗셈이 아니에요.
  • mkdir는 폴더를 만듭니다. exist_ok=True를 붙이면 폴더가 이미 있어도 오류가 나지 않아요.
  • touch는 파일이 없으면 빈 파일을 만듭니다. 같은 이름의 파일이 이미 있으면 내용은 그대로 두고 수정 시각만 바꿔요. 그래서 이 코드를 여러 번 실행해도 괜찮습니다.

만든 파일은 이름만 있는 빈 파일입니다. 엑셀로 열면 오류가 날 수 있어요. 이름 연습용으로만 쓰세요.

 

4단계: 폴더에서 이름 뽑기

이번 편의 본론입니다. 같은 폴더에 file_list.py로 저장하고 F5를 누르세요.

from pathlib import Path

folder = Path(__file__).parent / "샘플"
files = sorted(folder.iterdir())

for file in files:
    print(file.name)

print(f"모두 {len(files)}개")

[[ 이미지: 실행 결과 (05-실행-결과.png) ]]

  • folder.iterdir()는 폴더 바로 안에 있는 파일과 폴더를 하나씩 돌려줍니다. 그 폴더 속 폴더의 안쪽까지 뒤지지는 않아요.
  • sorted( )는 이름을 기준으로 줄을 세웁니다. 파이썬 공식 문서에 따르면 iterdir()만 쓰면 순서가 정해져 있지 않아요.
  • file.name은 경로를 뺀 파일 이름만 꺼냅니다.
  • 마지막 줄은 1편에서 배운 글자 끼워 넣기(f)입니다. 리스트의 칸 수를 문장 안에 넣었어요.

파이썬은 이름의 글자 순서(문자 코드 순)로 정렬합니다. 이 예제에서는 숫자가 먼저, 한글이 그다음으로 나왔어요. 윈도우 탐색기의 정렬 결과와는 다를 수 있습니다.

지금 코드는 파일과 폴더를 구분하지 않습니다. 샘플 폴더 안에 폴더가 있으면 그 폴더 이름도 함께 나와요. 폴더를 빼는 방법은 4편에서 다룹니다.

 

목록을 엑셀로 옮기려면?

Shell 창에 출력된 결과는 마우스로 선택해 복사할 수 있습니다.

[[ 이미지: 엑셀에 붙이기 (06-엑셀에-붙이기.png) ]]

  • Shell 창에서 파일 이름 줄들을 마우스로 끌어 선택합니다.
  • Ctrl+C로 복사합니다.
  • 엑셀의 A1 칸을 누르고 Ctrl+V로 붙입니다. 보통 한 줄이 한 칸씩 들어가요.

엑셀 버전이나 설정에 따라 붙는 모양이 조금 다를 수 있어요.

결과를 엑셀 파일로 바로 저장하는 방법은 10편에서 다룹니다. 지금은 복사만으로 충분해요.

 

안 될 때 확인할 것

오류 메시지는 맨 아랫줄부터 보세요. 이번 편에서 자주 만날 수 있는 오류를 정리했습니다. 아래는 맨 아랫줄의 앞부분만 옮긴 것이에요.

[[ 이미지: 안 될 때 (07-안-될-때.png) ]]

  • IndentationError: expected an indented block — for 아래 줄을 들여쓰지 않았어요. 스페이스 4칸을 넣으세요.
  • SyntaxError: expected ':' — for 줄 끝의 쌍점(:)이 빠졌습니다.
  • FileNotFoundError와 '지정된 경로를 찾을 수 없습니다' — 코드가 가리키는 폴더를 찾지 못했어요. 3단계 코드를 먼저 실행했는지, 두 코드 파일이 같은 폴더에 있는지, 폴더 이름('샘플')을 똑같이 썼는지 확인하세요.
  • NameError: name '__file__' is not defined — 코드를 Shell 창에 한 줄씩 넣었을 때 납니다. 새 파일에 쓰고 저장한 뒤 F5로 실행하세요.

리스트에서 없는 번호를 부르면 IndexError: list index out of range가 납니다. 세 칸짜리에서 names[3]을 부른 경우예요. 번호는 0부터라는 것을 떠올리세요.

 

오늘의 미션

  • print(file.name)을 print(file.name, file.suffix)로 바꿔 보세요. 이름 옆에 .xlsx, .pdf 같은 확장자가 붙어 나옵니다.
  • 3단계 리스트에 이름 하나를 더 넣고 다시 실행해 보세요. 4단계 결과가 '모두 9개'로 바뀌는지 확인합니다.
  • 1단계 코드에서 names[0]을 names[2]로 바꿔 보세요. 무엇이 나올지 먼저 맞혀 보고 실행합니다.

 

목록을 볼 수 있으면, 바꿀 수도 있습니다

오늘은 이름을 담고(리스트), 하나씩 꺼내(for), 폴더에서 가져왔습니다.

다음 3편에서는 이 목록을 한 걸음 더 씁니다. 꺼낸 이름마다 앞에 날짜를 붙여 한 번에 바꿔 봅니다. 1편의 날짜 이름표가 다시 나와요.

파일 이름을 실제로 바꾸는 편이라, 바꾸기 전에 미리보기부터 출력하는 습관도 함께 들입니다.
