방향키를 누르면 거북이가 움직여요. 빨간 먹이를 잡으면 점수가 1점 올라가고, 먹이는 다른 곳으로 휙 옮겨 가요.

오늘 만들 게임

[[ 이미지: 게임 규칙 (03-게임-규칙.png) ]]

  • ↑ 위 화살표를 눌렀다 놓으면 — 보고 있는 쪽으로 20만큼 앞으로
  • ← 왼쪽 화살표를 눌렀다 놓으면 — 왼쪽으로 30도 돌기
  • → 오른쪽 화살표를 눌렀다 놓으면 — 오른쪽으로 30도 돌기
  • 먹이에 닿으면 점수 +1, 먹이는 아무 데로나 이동

새로 배우는 건 네 가지예요. 함수, onkey, distance와 if, random.

파이썬이 아직 없다면 맨 아래 링크한 설치 글을 먼저 보고 오세요.

 

등장인물 만들기: 거북이와 먹이

import turtle
import random

t = turtle.Turtle()
t.shape("turtle")
t.color("green")
t.penup()

food = turtle.Turtle()
food.shape("circle")
food.color("red")
food.penup()
food.goto(100, 0)

score = 0

거북이를 두 마리 만들었어요. 하나는 우리가 움직일 초록 거북이 t, 하나는 동그란 빨간 먹이 food예요. turtle에서는 먹이도 거북이 한 마리로 만들고 모양만 동그라미로 바꿔요.

penup()은 펜을 들라는 뜻이에요. 게임에서는 지나간 자리에 선이 남지 않게 해요.

goto(100, 0)은 먹이를 오른쪽으로 100만큼 떨어진 곳에 놓아요. 거북이는 처음에 오른쪽을 보고 있으니, 위 화살표만 몇 번 누르면 첫 먹이를 잡을 수 있어요. 맨 아래 score = 0은 점수를 담을 상자예요.

 

키를 누르면 할 일, 함수로 묶기

def turn_left():
    t.left(30)

def turn_right():
    t.right(30)

def는 "이런 이름으로 할 일을 묶어 둘게"라는 뜻이에요. 들여쓰기 한 줄들이 그 묶음에 들어가요. 적어 두기만 하고, 부를 때 실행돼요.

🧩 쉽게 이해하기 — 리모컨 버튼

리모컨 버튼 하나에는 "채널 올리기"처럼 할 일이 정해져 있죠. 버튼을 누르기 전에는 아무 일도 안 일어나요. 함수도 똑같아요. turn_left라는 버튼을 만들어 두고, 다음 단계에서 그 버튼을 키보드 키에 붙일 거예요.

[[ 이미지: 키와 함수 연결 (04-키와-함수-연결.png) ]]

 

▸ 키에 함수 붙이기: onkey와 listen

아래 코드는 키와 함수를 연결하는 부분이에요. 실제로 실행할 때는 go, turn_left, turn_right 함수를 먼저 만들어 둔 다음 이 코드를 넣어야 해요. 마지막 전체 코드에서 순서를 다시 확인해 볼게요.

screen = turtle.Screen()
screen.onkey(go, "Up")
screen.onkey(turn_left, "Left")
screen.onkey(turn_right, "Right")
screen.listen()

onkey(go, "Up")는 "위 화살표를 눌렀다 놓으면 go를 불러 줘"라는 약속이에요. 키를 누르는 순간이 아니라, 눌렀던 키를 놓을 때 함수가 실행돼요. listen()은 거북이 창이 키보드에 귀를 기울이게 해요. 이 줄이 없으면 키를 눌러도 반응하지 않아요.

💡 파이의 꿀팁: onkey에는 함수 이름만 써요. go 뒤에 괄호를 붙이지 않는 게 핵심이에요. 왜 그런지는 아래 '일부러 틀려 보기'에서 볼게요.

 

먹이를 잡았을까?

이제 게임의 핵심인 go 함수예요. 앞으로 가고, 먹이에 닿았는지 확인해요.

def go():
    global score
    t.forward(20)
    if t.distance(food) < 20:
        score = score + 1
        print("점수:", score)
        x = random.randint(-200, 200)
        y = random.randint(-200, 200)
        food.goto(x, y)

t.distance(food)는 초록 거북이와 빨간 먹이의 중심 사이가 얼마나 떨어져 있는지 재요. 그 거리가 20보다 작으면 잡은 것으로 판정하도록 규칙을 정했어요.

if 아래 들여쓰기 한 줄들은 조건이 맞을 때만 실행돼요. 점수를 1 올리고, 화면에 알려 주고, 먹이를 옮겨요.

[[ 이미지: 닿았는지 재는 법 (05-닿았는지-재는-법.png) ]]

🧩 쉽게 이해하기 — 술래잡기

술래잡기에서 술래 손이 닿을 만큼 가까워지면 잡힌 거죠. 컴퓨터는 '닿았다'를 눈으로 못 보니까, 거북이와 먹이의 중심 사이 거리를 재서 "20보다 가까우면 잡힌 걸로 하자"라고 규칙을 정해 주는 거예요. 화면에서 두 모양의 테두리가 맞닿았는지를 보는 건 아니에요.

random.randint(-200, 200)은 -200부터 200 사이에서 정수 하나를 아무거나 뽑아요. 그래서 먹이가 매번 다른 곳으로 가요.

하나 맞혀 볼까요? 거리 기준 20을 5로 바꾸면 게임은 쉬워질까요, 어려워질까요?

정답은 어려워진다예요. 거의 정확히 겹쳐야만 잡히거든요. 숫자 하나로 게임 난이도가 바뀌어요.

 

▸ global score는 왜 있을까?

score 상자는 함수 바깥에 있어요. 함수 안에서 그 값을 바꾸려면 "바깥에 있는 그 score를 쓸게요"라고 먼저 말해 줘야 해요. 그게 global score예요.

 

모아서 실행해 볼까요?

import turtle
import random

t = turtle.Turtle()
t.shape("turtle")
t.color("green")
t.penup()

food = turtle.Turtle()
food.shape("circle")
food.color("red")
food.penup()
food.goto(100, 0)

score = 0

def go():
    global score
    t.forward(20)
    if t.distance(food) < 20:
        score = score + 1
        print("점수:", score)
        x = random.randint(-200, 200)
        y = random.randint(-200, 200)
        food.goto(x, y)

def turn_left():
    t.left(30)

def turn_right():
    t.right(30)

screen = turtle.Screen()
screen.onkey(go, "Up")
screen.onkey(turn_left, "Left")
screen.onkey(turn_right, "Right")
screen.listen()

turtle.done()

일부러 틀려 보기

 

▸ onkey(go(), "Up")처럼 괄호를 붙이면?

실행하자마자 거북이가 혼자 한 칸 움직여요. 그리고 그 뒤로는 위 화살표를 눌렀다 놓아도 꼼짝하지 않아요. 오류 메시지도 없어요.

원래 go는 위 화살표를 놓을 때 실행돼야 해요. 그런데 괄호를 붙이면 "지금 당장 go를 실행해"가 되어, 키를 누르기도 전에 프로그램이 시작하자마자 한 번 실행돼 버려요. 키에 붙여야 할 버튼을 미리 눌러 버린 셈이에요. 그래서 onkey에는 괄호 없이 이름만 써요.

 

▸ global score를 빼먹으면?

거북이는 잘 움직이는데, 먹이에 닿는 순간 Shell에 빨간 글씨가 나와요.

UnboundLocalError: cannot access
local variable 'score' where it is
not associated with a value

"함수 안에 score라는 상자가 있는 줄 알았는데, 아직 아무것도 안 들어 있어요"라는 뜻이에요. 바깥의 score를 쓴다고 말해 주지 않아서 생긴 일이에요.

 

오늘의 숙제: 내 게임으로 바꾸기

🎯 파이의 숙제

  • forward(20)을 forward(30)으로 바꿔 거북이를 빠르게 만들기
  • left(30)·right(30)을 90으로 바꿔 보고, 어느 쪽이 조종하기 쉬운지 비교하기
  • 먹이 모양 "circle"을 "square"로, 색을 "blue"로 바꾸기
  • 도전: 아래 화살표("Down")를 누르면 뒤로 가는 함수를 만들어 붙이기 (힌트: t.backward(20))

 

누르고, 확인하고, 반응하고

오늘 만든 게임은 세 가지를 되풀이해요. 키가 눌리면(입력), 먹이에 닿았는지 확인하고(조건), 점수를 올리고 먹이를 옮겨요(반응).

훨씬 화려한 게임도 이 세 가지를 아주 빠르게, 아주 많이 되풀이하며 움직여요.
