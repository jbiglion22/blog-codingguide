# 업로드 문구 — 파이썬 거북이 게임 (앱 등록 화면 순서)

네이버 클립 앱 등록 화면을 위에서부터 이 순서대로 채운다.

## 1. 영상 파일
- `clip/거북이게임-클립.mp4` (1080×1920, 38초, 음악 포함, 더빙 없음, 캐릭터가 살짝씩 움직임)
- `clip/02-내가-만든-게임.mp4`가 남아 있으면 예전 순서의 파일이니 쓰지 않는다.

## 2. 설명 * (최대 3,000자)
콘텐츠 링크(5번)에 블로그 글을 연결하면 아래 글을 그대로 붙인다. 첫 줄 「🐍 파이썬으로 게임 만들기」는 무슨 영상인지 바로 알리려고 넣었다(2026-11-25, 이미 올린 영상은 파일을 바꿀 수 없어 설명으로 보완). 연결 칸이 없으면 맨 아래 '주소 포함' 글을 쓴다.

```
🐍 파이썬으로 게임 만들기 | 방향키로 거북이를 몰아 빨간 먹이를 잡는 작은 게임이에요. 잡을 때마다 +1점, 먹이는 휙 다른 곳으로!
코드 30줄 남짓이면 만들 수 있어요.
따라 만드는 순서와 전체 코드는 블로그 글에서 알려 드려요.

※ 영상 속 그림은 설명용 일러스트이고, 다섯 번째 장면이 실제로 실행한 게임 화면이에요.

#파이썬 #파이썬기초 #파이썬게임 #파이썬터틀 #turtle #거북이게임 #코딩기초 #코딩교육
```

주소 포함(콘텐츠 링크를 쓸 수 없을 때):
```

코드 30줄 남짓이면 만들 수 있어요.
따라 만드는 순서와 전체 코드는 블로그 글에서 알려 드려요.

https://blog.naver.com/codingguide/224490313555

※ 영상 속 그림은 설명용 일러스트이고, 다섯 번째 장면이 실제로 실행한 게임 화면이에요.

#파이썬 #파이썬기초 #파이썬게임 #파이썬터틀 #turtle #거북이게임 #코딩기초 #코딩교육
```

## 3. 카테고리 *
- **1차 `테크` > 2차 `IT, 컴퓨터`** (앱이 추천으로 보여 준 항목)
- 배우기 쪽으로 넣고 싶으면 `교육` > `자기계발, 취미레슨`.
- '게임' 계열은 고르지 않는다(시청자가 판매용 게임 영상으로 오해할 수 있음).

## 4. 정보 태그
- **넣지 않음.** '게임' 태그는 시중 게임 정보를 연결하는 기능으로 보이는데, 이 게임은 직접 만든 연습용이라 연결할 게임이 없다.

## 5. 콘텐츠 링크
- **블로그**를 고르고 아래 글을 연결한다(네이버TV·뉴스는 고르지 않는다).
- 글: 「파이썬 거북이 게임 만들기, 방향키로 먹이 잡기」
- 주소: `https://blog.naver.com/codingguide/224490313555`

## 6. 재생목록
- 추천: 새 재생목록 **「파이썬 코딩 클립」**을 만들어 넣는다(다음 코딩 클립도 같은 목록에).
- 쓰지 않을 거면 건너뛴다.

## 7. 공개 설정
- **전체 공개**(켠 그대로). 예약 두 칸은 체크하지 않는다.
- 예약하고 싶으면 공개 예약으로 저녁 시간(오후 8~10시)을 고른다.

## 8. 올리기 전 확인
- 미리보기에서 위쪽 자막과 장면 아래 '설명용 일러스트' 안내가 앱 화면에 가려지지 않는지 본다.
- 음악이 나오는지 들어 본다.
- AI가 만든 그림·음악에 대한 표시 요구가 앱에 있으면 따른다.
