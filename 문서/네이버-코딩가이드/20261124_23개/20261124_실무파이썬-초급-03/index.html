왜 미리보기부터 할까?

코드로 바꾼 이름은 탐색기의 되돌리기(Ctrl+Z)로 돌릴 수 없다고 생각하는 게 안전합니다.

그래서 코드를 두 개로 나눕니다.

[[ 이미지: 미리보기 먼저 (03-미리보기-먼저.png) ]]

  • 미리보기 코드: 바뀔 이름을 화면에 보여 주기만 합니다. 파일은 그대로예요.
  • 바꾸기 코드: 미리보기가 마음에 들 때만, 한 번 실행합니다.

실제 업무 파일이라면 폴더를 통째로 복사해 두고 복사본에서 먼저 해 보세요.

 

1단계: 바뀔 이름 미리보기

파이썬연습 폴더에 preview.py로 저장하고 F5를 누르세요. make_samples.py와 같은 폴더여야 합니다.

from datetime import date
from pathlib import Path

folder = Path(__file__).parent / "샘플"
stamp = date.today().strftime("%Y%m%d")

for file in sorted(folder.iterdir()):
    new_name = f"{stamp}_{file.name}"
    print(file.name, "→", new_name)

실행한 뒤 탐색기에서 샘플 폴더를 열어 보세요. 이름은 하나도 바뀌지 않았습니다.

▶ 모두 앞에서 배운 줄입니다

  • stamp: 1편에서 배운 오늘 날짜입니다. %Y%m%d라서 20261124 모양이 돼요.
  • for file in sorted(...): 2편의 파일 목록을 하나씩 꺼냅니다.
  • new_name: f-string으로 '날짜_원래 이름'을 만든 새 이름표예요.
  • print(a, "→", b): 쉼표로 이은 값들은 한 칸씩 띄어 한 줄에 나옵니다.

 

2단계: 확인했으면 진짜로 바꾸기

미리보기 코드에 한 줄을 더합니다. 같은 폴더에 rename.py로 저장하고 F5를 누르세요.

from datetime import date
from pathlib import Path

folder = Path(__file__).parent / "샘플"
stamp = date.today().strftime("%Y%m%d")

files = sorted(folder.iterdir())
for file in files:
    new_name = f"{stamp}_{file.name}"
    file.rename(folder / new_name)
    print(new_name)

print(f"{len(files)}개를 바꿨습니다.")

[[ 이미지: 실행 결과 (04-실행-결과.png) ]]

이번에는 탐색기의 이름이 정말 바뀌어 있습니다.

▶ 새로 나온 한 줄

  • file.rename(새 위치): 파일의 이름(위치)을 바꿉니다.
  • folder / new_name: '샘플 폴더 안의 새 이름'이라는 뜻입니다. 2편의 folder / name과 같은 방식이에요.

여기서 folder /를 빼고 file.rename(new_name)이라고만 쓰면 어떻게 될까요?

파일이 샘플 폴더에서 사라집니다. 대신 코드 파일이 있는 파이썬연습 폴더에 새 이름으로 옮겨져 있어요.

파이썬 공식 문서도 폴더 없이 쓴 새 이름은 '지금 작업 중인 폴더' 기준이라고 설명합니다. IDLE에서 F5로 실행하면 그 폴더가 코드 파일이 있는 폴더예요.

 

두 번 실행하면 어떻게 될까?

rename.py를 한 번 더 실행하면 날짜가 또 붙습니다.

[[ 이미지: 두 번 실행하면 (05-두-번-실행하면.png) ]]

코드는 시킨 대로 했을 뿐입니다. 이미 날짜가 붙은 이름인지 따져 보라고는 하지 않았으니까요.

'이미 붙어 있으면 건너뛰어라'를 시키려면 if가 필요합니다. 4편에서 배워요. 그때까지는 바꾸기 코드를 한 번만 실행하세요.

▶ 연습을 처음부터 다시 하려면

  • 탐색기에서 샘플 폴더를 통째로 지웁니다.
  • 2편의 make_samples.py를 다시 실행합니다.
  • 원래 이름의 빈 파일 8개가 다시 생깁니다.

연습 파일은 빈 파일이라 이렇게 해도 괜찮습니다. 실제 업무 파일은 지우지 마세요.

 

안 될 때 확인할 것

오류 메시지는 맨 아랫줄부터 보세요. 아래는 맨 아랫줄의 앞부분만 옮긴 것이에요.

[[ 이미지: 안 될 때 (06-안-될-때.png) ]]

  • PermissionError: [WinError 32] '다른 프로세스가 파일을 사용 중' — 그 파일이 다른 프로그램에 열려 있어요. 엑셀 등에서 파일을 닫고 다시 실행하세요.
  • FileExistsError: [WinError 183] '파일이 이미 있으므로' — 바꾸려는 새 이름의 파일이 이미 폴더에 있습니다. 윈도우에서는 같은 이름으로 덮어쓰지 않고 멈춰요.
  • FileNotFoundError — 샘플 폴더를 찾지 못했어요. 2편처럼 저장 위치와 폴더 이름을 확인하세요.

오류로 멈추면 그 앞의 파일들은 이미 바뀌어 있습니다. 예를 들어 세 번째 파일이 열려 있으면, 앞의 두 개만 바뀌고 멈춥니다.

이럴 때 rename.py를 그냥 다시 실행하면 앞쪽 파일에는 날짜가 두 번 붙습니다. 연습 중이라면 샘플 폴더를 새로 만드는 쪽이 깔끔해요.

 

오늘의 미션

미션은 모두 preview.py에서 해 보세요. 이름이 바뀌지 않으니 마음껏 고쳐도 됩니다.

  • %Y%m%d를 %Y-%m-%d로 바꿔 보세요. 2026-11-24_1월_매출.xlsx처럼 나옵니다.
  • 날짜를 뒤로 보내 보세요. new_name 줄을 f"{file.stem}_{stamp}{file.suffix}"로 바꾸면 1월_매출_20261124.xlsx가 됩니다. stem은 확장자를 뺀 이름이에요.
  • 날짜 대신 검토완료_를 붙여 보세요.

 

코드에게 '따져 보라'고 시키는 다음 걸음

오늘은 미리보기로 확인하고, 한 줄을 더해 이름을 한 번에 바꿨습니다.

남은 숙제는 두 가지입니다. 날짜가 이미 붙은 파일은 건너뛰기, 폴더는 빼고 파일만 다루기.

둘 다 '이러면 이렇게 해라'를 시키는 if로 풀립니다. 다음 4편에서는 if로 다운로드 폴더를 종류별로 정리해 봅니다.
