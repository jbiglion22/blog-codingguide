오늘은 이 이름을 파이썬이 대신 짓게 만들어 봅니다. 코드는 몇 줄이면 됩니다.

이번 글에서는 이름 글자를 만들어서 화면에 보여 주는 것까지만 합니다. 실제 파일 이름을 바꾸는 건 3편에서 해요. 먼저 이름을 정확히 만드는 연습부터입니다.

 

1단계: 오늘 날짜를 파이썬에게 물어보기

IDLE에서 File → New File로 빈 창을 열고, 아래 네 줄을 입력해 보세요. 저장하지 않고 바로 F5를 눌러도 되지만, 저장 이름을 물어보면 파이썬연습 폴더에 저장하면 됩니다.

from datetime import date

today = date.today()
print(today)

실행하면 컴퓨터의 오늘 날짜가 나옵니다. 실행한 컴퓨터의 날짜가 2026년 11월 19일이라면 이렇게 나와요.

2026-11-19

한 줄씩 풀어 볼게요.

  • from datetime import date — 파이썬에는 날짜를 다루는 도구가 들어 있습니다. 그 도구 상자(datetime)에서 date라는 도구를 꺼내 온다는 뜻이에요. 프로그램 맨 위에 한 번만 쓰면 됩니다.
  • today = date.today() — 오늘 날짜를 알아내서 today라는 이름표를 붙입니다. 이렇게 값에 이름표를 붙인 것을 변수라고 불러요. 여기서 =는 '같다'가 아니라 '넣는다'는 뜻입니다.
  • print(today) — 이름표 today가 가리키는 값을 화면에 보여 줍니다.

날짜는 이 컴퓨터의 시계를 기준으로 나옵니다. 컴퓨터 시계가 틀려 있으면 날짜도 틀리게 나와요.

 

2단계: 파일 이름 조립하기

이제 보고서 이름과 날짜를 이어 붙여 봅니다. 앞의 코드를 아래처럼 바꿔 주세요. 컴퓨터의 날짜가 2026년 11월 19일이라면, 결과는 코드 바로 아래 같은 모양으로 나옵니다.

from datetime import date

name = "월간보고서"
today = date.today()
file_name = f"{name}_{today}.xlsx"
print(file_name)
월간보고서_2026-11-19.xlsx

[[ 이미지: 이름표와 조립 (04-이름표와-조립.png) ]]

  • name = "월간보고서" — 글자에도 이름표를 붙일 수 있어요. 글자는 따옴표로 감쌉니다.
  • f"{name}_{today}.xlsx" — 따옴표 앞의 f가 핵심입니다. 중괄호 { } 안에 이름표를 쓰면 그 자리에 값이 끼워 들어가요. 중괄호 밖의 _와 .xlsx는 글자 그대로 나옵니다. .xlsx는 엑셀 파일을 뜻하는 끝 표시예요.
  • file_name — 완성된 이름에도 이름표를 붙였습니다. 다음 편들에서 이 이름표를 다시 쓸 거예요.

여기까지는 이름 글자를 만든 것일 뿐, 파일이 생기지는 않았습니다.

 

3단계: 날짜 모양 바꾸기

지금은 날짜가 2026-11-19처럼 하이픈(-)으로 이어져 나옵니다. 회사에서 20261119처럼 붙여 쓰자고 정했다면요? 날짜를 원하는 모양의 글자로 바꿔 주는 기능이 있습니다.

stamp = today.strftime("%Y%m%d")

strftime 괄호 안의 글자는 '날짜를 이런 모양으로 써 줘'라는 주문서예요. 파이썬 공식 문서에 나온 글자 몇 개만 알면 됩니다.

  • %Y — 네 자리 연도 (2026)
  • %m — 두 자리 월 (11)
  • %d — 두 자리 일 (19)
  • %y — 두 자리 연도 (26). 대문자 Y와 소문자 y는 다릅니다.

[[ 이미지: 날짜 모양 표 (05-날짜-모양-표.png) ]]

주문서 글자 사이에 넣은 하이픈이나 점은 그대로 나옵니다. "%Y-%m-%d"는 2026-11-19, "%y%m%d"는 261119가 돼요.

파일 이름에 쓸 수 없는 글자

날짜 사이에 슬래시(/)를 넣어 "%Y/%m/%d"로 쓰면 날짜는 2026/11/19로 나옵니다. 하지만 이 글자는 파일 이름으로 쓸 수 없어요. 마이크로소프트 공식 문서에 따르면 윈도우 파일 이름에는 다음 글자를 쓸 수 없습니다.

<  >  :  "  /  \  |  ?  *

날짜 사이에는 하이픈(-)이나 밑줄(_)을 쓰거나, 아무것도 넣지 않는 방식이 무난합니다. 점(.)도 이름 중간에는 쓸 수 있지만, 마이크로소프트 공식 문서는 파일 이름의 맨 끝에 점이나 공백을 두지 말라고 안내합니다. 이 글의 이름은 .xlsx로 끝나서 걱정하지 않아도 됩니다.

 

전체 코드 실행하기

지금까지 배운 것을 모아 완성해 봅니다. IDLE에서 새 파일을 열고 아래 코드를 입력한 뒤, 파이썬연습 폴더에 report_name.py라는 이름으로 저장하세요. 그다음 F5를 누릅니다.

from datetime import date

name = "월간보고서"
today = date.today()
stamp = today.strftime("%Y%m%d")

file_name = f"{name}_{stamp}.xlsx"
print(file_name)

2026년 11월 19일에 실행하면 이렇게 나옵니다.

[[ 이미지: 실행 결과 (06-실행-결과.png) ]]

다음 달에 실행하면 이름의 날짜 부분이 저절로 바뀝니다. 코드는 한 글자도 고치지 않았는데도요.

 

안 될 때 확인할 것

0편에서 말씀드린 것처럼 오류 메시지는 맨 아랫줄이 핵심입니다. 이번 글에서 자주 만날 실수 네 가지예요.

[[ 이미지: 안 될 때 (07-안-될-때.png) ]]

  • ImportError: cannot import name 'Date' from 'datetime' — date를 대문자 D로 썼어요. 메시지 끝에 Did you mean: 'date'?(혹시 date를 말씀하신 건가요?)라고 파이썬이 알려 줍니다. 이런 제안은 믿어 봐도 좋아요.
  • NameError: name 'today' is not defined — today를 만들기 전에 썼거나, 이름표를 다르게 썼습니다. today와 tody는 파이썬에게 완전히 다른 이름이에요.
  • 결과에 {name}_{stamp}.xlsx가 그대로 나올 때 — 오류는 아니지만, 문자열을 감싼 따옴표 바로 앞에 f를 붙이지 않은 경우입니다. f가 붙어 있어야 중괄호 안에 값이 들어가요.
  • SyntaxError: unterminated f-string literal — 글자를 감싼 닫는 따옴표가 빠졌습니다. 0편에서 본 따옴표 실수와 같아요.
