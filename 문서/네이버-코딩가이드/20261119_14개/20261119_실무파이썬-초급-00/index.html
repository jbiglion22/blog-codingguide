월말 금요일 오후, 폴더에 지점별 엑셀 파일이 열두 개 쌓여 있다고 해 볼게요. 하나씩 열어서 복사하고, 합칠 파일에 붙여 넣고, 다시 다음 파일을 엽니다. 한 시간이 금방 지나갑니다.

이런 일은 코드 몇 줄이면 끝나기도 합니다. 그리고 그 코드를 쓰는 법은 생각보다 어렵지 않아요.

오늘부터 「초보도 업무에서 바로 쓰는 파이썬」을 연재합니다. 코딩을 한 번도 해 본 적 없어도 괜찮습니다. 이번 0편에서는 파이썬을 설치하고, 화면에 첫 글자를 띄워 보는 데까지만 갑니다.

 

이 연재는 이렇게 진행합니다

글 제목 앞에는 [실무 파이썬 초급 1강]처럼 붙입니다. 초급을 마치면 조금 더 어려운 중급으로 이어 갈 계획이에요.

  • 한 편에 업무 하나를 끝냅니다. 파일 이름 바꾸기, 폴더 정리, 엑셀 합치기 같은 실제 일이에요.
  • 문법은 필요할 때 하나씩만 나옵니다. '변수가 무엇인가'부터 외우는 순서가 아니에요. 일을 하다 보면 자연스럽게 따라옵니다.
  • 안내한 환경에서 실행을 확인한 코드만 싣습니다. 윈도우 PC에서 돌려 보고 결과를 확인했고, 파이썬 버전이나 설정에 따라 달라질 수 있는 부분은 그때그때 알려 드릴게요.
  • 어려운 말은 최대한 쉬운 말로 풀고, 꼭 필요한 용어만 괄호로 적습니다.

[[ 이미지: 연재 지도 (02-연재-지도.png) ]]

초급은 모두 13편입니다. 앞쪽은 파일과 폴더를 다루는 일, 가운데는 엑셀, 뒤쪽은 보고서와 PDF 순서예요. 이 글은 윈도우 PC를 기준으로 씁니다.

 

파이썬이 대신해 주는 일

앞으로 이런 일을 하나씩 해 볼 거예요.

  • 폴더 속 파일 이름 100개를 한 번에 바꾸기
  • 다운로드 폴더를 문서·사진별로 정리하기
  • 엑셀 파일 12개를 하나로 합치고, 기준을 넘는 칸에 색칠하기
  • PDF 여러 개를 하나로 붙이기

[[ 이미지: 저녁 책상 (03-저녁-책상.png) ]]

다만 모든 일을 대신해 주지는 않아요. 파이썬이 잘하는 일은 같은 일을 되풀이하는 것입니다. 처음 한 번은 코드를 만드는 시간이 들지만, 그다음부터는 실행 한 번이면 돼요.

 

시작하기 전에, 회사 PC라면

회사 컴퓨터는 프로그램을 마음대로 설치할 수 없게 막아 둔 곳이 많습니다.

  • 설치하기 전에 IT 담당자나 보안 규정을 먼저 확인해 주세요.
  • 설치가 허용되지 않는다면 개인 PC에서 먼저 연습하세요. 실제 업무에 적용할 때는 회사의 보안 규정과 프로그램 사용 정책을 다시 확인해야 합니다.
  • 연습할 파일은 이 연재에서 코드로 직접 만들어 드립니다. 회사 문서나 개인정보가 든 파일로 연습하지 마세요.

 

1단계: 파이썬 설치하기

윈도우에는 파이썬이 기본으로 들어 있지 않습니다. 파이썬 공식 문서가 권하는 방법으로 설치해 볼게요. 파이썬을 설치하고 관리해 주는 '설치 도우미(Python install manager)'를 먼저 받는 방식입니다.

  • 인터넷 브라우저에서 python.org/downloads에 들어갑니다.
  • 윈도우용 안내로 들어가 Python install manager를 내려받습니다. 마이크로소프트 스토어 앱에서 설치해도 같은 프로그램이라고 공식 문서가 안내합니다.
  • 스토어에서는 Install 버튼을 누르고, 내려받은 파일은 더블클릭해 Install을 고릅니다.
  • 설치가 끝나면 시작 메뉴에서 터미널(또는 명령 프롬프트)을 열어 python이라고 입력하고 엔터를 누릅니다. 설치된 파이썬이 없으면 최신 버전이 자동으로 설치돼요.

[[ 이미지: 설치 세 걸음 (04-설치-세-걸음.png) ]]

중간에 'PATH에 폴더를 추가하겠느냐'는 안내가 나올 수 있는데, 공식 문서는 이것이 선택 사항이라고 설명합니다. 지금은 몰라도 괜찮아요.

터미널에서 python을 실행하면 파이썬 대화형 셸이 열리고, 화면에 >>> 표시가 나타납니다. 이 표시는 설치 프로그램의 완료 표시가 아니라, 파이썬이 명령을 기다리고 있다는 입력 신호예요. 여기서 나가려면 exit()를 입력하세요. 버전 숫자는 시기에 따라 다를 수 있지만, 이 연재의 기초 코드는 같게 돌아갑니다.

 

2단계: IDLE 열고 첫 글자 띄우기

코드를 쓰려면 글을 쓰는 프로그램이 필요합니다. 파이썬 공식 배포판에는 IDLE이라는 프로그램이 함께 들어 있는 경우가 많아요(설치 구성에 따라 빠질 수도 있습니다). 코드를 쓰고 바로 실행해 볼 수 있는, 파이썬 공식 연습용 프로그램입니다.

  • 설치 방식에 따라 시작 메뉴 검색창에 IDLE이라고 입력하면 보일 수 있어요.
  • 보이지 않으면 터미널을 열어 python -m idlelib이라고 입력해 보세요. 공식 문서에 나온 실행 방법입니다.

IDLE이 열리면 Shell 창이 나타납니다. 이 창에서는 한 줄씩 입력하고 바로 결과를 볼 수 있어요.

[[ 이미지: IDLE 화면 읽기 (05-IDLE-화면-읽기.png) ]]

>>> 뒤에 아래 한 줄을 입력하고 엔터를 눌러 보세요.

print("안녕하세요, 파이썬!")

바로 아래에 안녕하세요, 파이썬!이 나타나면 성공입니다.

print는 괄호 안의 내용을 화면에 보여 주는 명령이에요. 따옴표(") 안에 있는 것은 글자로 취급합니다. 앞으로 가장 많이 만나게 될 명령이라서, 모양을 눈에 익혀 두면 좋아요.

 

3단계: 파일로 저장해서 실행하기

한 줄씩 입력하는 방식은 연습에는 좋지만, 업무에 쓰려면 코드를 파일로 저장해 두고 필요할 때 돌려야 합니다. 그래서 이 연재의 코드는 모두 파일로 저장해서 실행해요.

  • 바탕화면에 파이썬연습이라는 폴더를 하나 만듭니다. 앞으로 연습 파일은 모두 여기에 모을 거예요.
  • IDLE 위쪽 메뉴에서 File → New File을 누르면 빈 창이 열립니다.
  • 아래 세 줄을 그대로 입력합니다.
print("안녕하세요, 파이썬!")
print("오늘부터 업무 자동화를")
print(10 * 3)
  • File → Save를 눌러 파이썬연습 폴더에 hello.py라는 이름으로 저장합니다. 파일 이름 끝의 .py는 파이썬 파일이라는 표시예요.
  • 위쪽 메뉴에서 Run → Run Module을 누릅니다. 키보드 F5를 눌러도 같습니다.

IDLE 문서에 따르면 Run Module은 코드에 오류가 없을 때 실행하고, 결과를 Shell 창에 보여 줍니다. 아래와 같이 나오면 됩니다.

[[ 이미지: 실행 결과 (06-실행-결과.png) ]]

세 번째 줄을 보세요. 10 * 3은 '10 곱하기 3'이라서 30이 나왔습니다. 곱하기 기호는 *이고, 숫자는 따옴표 없이 씁니다. 따옴표로 감싸면 계산하지 않고 글자 그대로 보여 줘요.

 

안 될 때 확인할 것

처음에는 누구나 한 번쯤 빨간 글씨를 만납니다. 겁먹지 않아도 돼요. 오류 메시지는 맨 아랫줄이 핵심이고, 대부분 아주 사소한 실수입니다.

[[ 이미지: 안 될 때 (07-안-될-때.png) ]]

① 빨간 오류 메시지가 나올 때

  • SyntaxError: unterminated string literal — 글자를 감싼 따옴표 하나가 빠졌습니다. 닫는 따옴표를 확인하세요.
  • NameError: name 'Print' is not defined — print를 대문자 P로 썼어요. 파이썬은 대소문자를 구분합니다.
  • SyntaxError: invalid character '“' — 따옴표가 휘어진 모양으로 바뀌었어요. 글을 복사하는 과정에서 생기기도 합니다. 곧은 따옴표(")로 고쳐 주세요.
  • '(' was never closed — 괄호를 열고 닫지 않았습니다. 여는 괄호와 닫는 괄호의 개수를 맞춰 주세요.

② 터미널에서 python이 안 될 때

공식 문서의 안내에 따르면, 먼저 설치 도우미(Python install manager)를 설치했는지 확인합니다. 그다음 시작 메뉴에서 '앱 실행 별칭 관리'(영문: Manage app execution aliases)를 열어 Python (default) 항목이 켜져 있는지 보세요. 이미 켜져 있다면 껐다가 다시 켜 보라고 안내합니다.

③ IDLE이 열리지 않을 때

터미널에서 python -m idlelib을 입력해 보세요. 그래도 열리지 않는다면 IDLE이 설치되어 있지 않거나 실행 환경에 문제가 있을 수 있어요. IDLE은 선택 구성 요소라 설치 구성에 따라 빠질 수 있다고 공식 문서가 설명합니다. 설치 구성에 IDLE이 포함되어 있는지 확인하고, 빠져 있다면 IDLE이 포함되도록 설치 구성을 바꿔 주세요. 구체적인 화면은 설치 방식에 따라 다르니, 회사 PC라면 IT 담당자에게 물어보는 것이 가장 빠릅니다.

 

오늘의 미션

hello.py를 열어 세 가지를 해 보세요. 고친 뒤에는 저장하고 다시 F5를 누르면 됩니다.

  • 첫 줄의 글자를 내 이름이 들어간 인사로 바꿔 보세요.
  • 세 번째 줄을 print(4500 * 20)으로 바꿔 보세요. 커피 한 잔 4,500원을 20일 동안 마시면 얼마인지 계산한 거예요. 결과는 90000이 나옵니다.
  • 일부러 첫 줄의 닫는 따옴표를 지우고 실행해 보세요. 위에서 본 오류 메시지가 나오는지 확인해 보는 거예요. 오류를 한 번 만나 보면 다음에 덜 놀랍니다.
