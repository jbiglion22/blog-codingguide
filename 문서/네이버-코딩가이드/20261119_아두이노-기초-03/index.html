'아두이노 기초' 연재 3편입니다. 지난 2편에서는 프로그램을 설치하고 보드의 내장 LED를 깜빡였어요.

이번 편에서 만들 것

브레드보드에 꽂은 빨간 LED가 0.5초마다 켜졌다 꺼졌다 합니다. 우노 R3는 보드의 작은 L LED가 13번 핀에 이어져 있어서, L LED도 함께 깜빡여요(다른 호환 보드는 다를 수 있어요).

준비물: 우노 보드, USB 케이블, 브레드보드, 빨간 LED 1개, 220Ω 저항 1개, 점퍼선 2개

 

브레드보드 속은 어떻게 이어져 있을까

브레드보드는 구멍이 잔뜩 뚫린 하얀 판입니다. 납땜 없이 부품을 꽂기만 하면 회로를 만들 수 있어요. 겉으로는 구멍만 보이지만, 안쪽에는 금속판이 숨어 있어서 정해진 구멍끼리 전기가 통합니다.

  • 가운데 부분: 일반적인 브레드보드는 가운데 홈을 기준으로 양쪽에 5개 구멍씩 한 묶음으로 이어져 있습니다. 같은 묶음에 꽂은 부품끼리는 전선 없이도 연결돼요.
  • 가운데 홈: 홈을 사이에 둔 양쪽 묶음은 서로 끊겨 있습니다.
  • 가장자리의 +, - 줄: 길게 이어져 있어서 전원(+)과 GND(-)를 나눠 쓰기 좋습니다.

제품에 따라 안쪽 연결 방향이나 전원 줄 모양이 조금씩 다를 수 있으니, 처음 쓰는 브레드보드라면 설명서나 겉에 그려진 선으로 연결 구조를 확인하세요. 판을 돌려 놓으면 묶음 방향도 같이 돌아가요.

[[ 이미지: 브레드보드 속 (03-브레드보드-속.png) ]]

💡 두이의 꿀팁: 브레드보드에 따라 가장자리 전원 줄이 가운데쯤에서 끊긴 것도 있어. 줄 옆 빨간 선·파란 선이 중간에 끊겨 있으면 거기서 전기가 안 통한다는 표시야!

 

LED는 방향이 있다

LED는 거꾸로 꽂으면 켜지지 않습니다. 다리 두 개를 잘 보세요.

  • 긴 다리 = +(플러스): 전기가 들어가는 쪽입니다. 핀 쪽(저항 쪽)에 연결해요.
  • 짧은 다리 = -(마이너스): 전기가 나가는 쪽입니다. GND에 연결해요.
  • 다리를 잘랐다면, LED 동그란 테두리에서 평평하게 깎인 쪽이 -입니다.

저항은 왜 꼭 필요할까

저항은 전기가 너무 많이 흐르지 않게 막아 주는 부품입니다. 물로 비유하면 수도관 중간을 좁혀 물이 콸콸 쏟아지지 않게 하는 것과 같아요.

[[ 이미지: 저항은 좁은 수도관 (05-저항은-수도관.png) ]]

아두이노 공식 안내도 저항이 LED에 흐르는 전기(전류)를 줄여서 LED와 아두이노 핀이 망가지지 않게 해 준다며, 꼭 필요하다고 설명합니다. 저항 없이 꽂으면 전기가 너무 많이 흘러 LED뿐 아니라 아두이노 핀까지 망가질 수 있어요. 저항은 LED와 한 길로 이어지게(직렬로) 꽂아야 효과가 있습니다.

숫자로 확인해 보기

우노 R3 공식 사양에는 I/O 핀 하나당 전류가 20mA(밀리암페어)로 안내되어 있습니다. 이 값을 넘지 않게 쓰는 것이 좋아요. 220Ω 저항을 끼우면 얼마나 흐를까요? 전압을 저항으로 나누면 전류가 나옵니다(옴의 법칙).

  • 빨간 LED가 쓰는 전압(순방향 전압)을 약 2V로 가정합니다.
  • 핀 전압 5V에서 2V를 빼면 → 3V
  • 3V ÷ 220Ω ≈ 0.014A = 약 14mA
  • 14mA는 20mA보다 작아요.

이 숫자는 가정으로 계산한 이론값이라, 실제 전류는 LED와 저항에 따라 조금 달라집니다. 공식 안내에도 우노에서는 220Ω이면 LED와 핀 모두에 안전한 수준이라고 나와 있습니다. 저항을 더 크게(최대 1kΩ 정도) 하면 LED가 조금 어두워지지만 여전히 보여요.

💡 두이의 꿀팁: 저항은 몸에 그려진 색 띠로 크기를 알 수 있어. 220Ω은 보통 빨강·빨강·갈색(+금색) 띠야. 저항은 LED와 달리 방향이 없어서 어느 쪽으로 꽂아도 돼!

 

회로 연결하기

USB 케이블을 뽑은 상태에서 아래 순서대로 꽂으세요.

  • ① LED를 브레드보드에 꽂습니다. 긴 다리와 짧은 다리가 서로 다른 줄에 들어가게 해요.
  • ② 저항의 한쪽 다리를 LED 긴 다리와 같은 줄에, 다른 쪽 다리는 옆의 빈 줄에 꽂습니다.
  • ③ 점퍼선으로 보드의 13번 핀과 저항의 빈 쪽 줄을 잇습니다.
  • ④ 점퍼선으로 보드의 GND와 LED 짧은 다리 줄을 잇습니다.

[[ 이미지: 배선도 (06-배선도.png) ]]

LED가 켜질 때 전류가 흐르는 경로는 13번 핀 → 저항 → LED 긴 다리 → LED 짧은 다리 → GND입니다. 이 길이 끊긴 곳 없이 이어져야 LED가 켜져요.

 

코드 쓰기

2편 코드와 거의 같지만, 이번엔 핀 번호에 이름을 붙여 봤어요.

int ledPin = 13;   // LED를 꽂은 핀 번호에 '이름' 붙이기

void setup() {
  pinMode(ledPin, OUTPUT);   // ledPin(13번)을 출력으로 쓰기
  Serial.begin(9600);
  Serial.println("브레드보드 LED 준비 완료!");
}

void loop() {
  digitalWrite(ledPin, HIGH);   // LED 켜기
  Serial.println("LED 켜짐");
  delay(500);                   // 0.5초 기다리기
  digitalWrite(ledPin, LOW);    // LED 끄기
  Serial.println("LED 꺼짐");
  delay(500);                   // 0.5초 기다리기
}
  • int ledPin = 13; — '13'이라는 숫자에 ledPin이라는 이름표를 붙였습니다. 이런 이름표를 변수라고 해요. int는 '정수(소수점 없는 수)를 담는다'는 뜻입니다.
  • 이름표를 쓰면 좋은 점: 나중에 LED를 8번 핀으로 옮겨도 첫 줄의 숫자 하나만 바꾸면 됩니다.
  • delay(500); — 500밀리초, 즉 0.5초 기다립니다. 2편보다 두 배 빠르게 깜빡여요.

 

업로드하고 결과 보기

USB 케이블을 꽂고, 2편에서 한 것처럼 체크(✓)로 확인한 뒤 화살표(→)로 업로드하세요.

[[ 이미지: 실행 결과 (07-실행-결과.png) ]]

브레드보드의 LED가 0.5초마다 깜빡이고, 우노 R3라면 보드의 L LED도 함께 깜빡입니다. 시리얼 모니터(속도 9600)에는 "브레드보드 LED 준비 완료!"가 한 번 나오고, "LED 켜짐"과 "LED 꺼짐"이 번갈아 나와요.

※ 회로를 바르게 연결하고 업로드했다면 그림처럼 동작합니다.

 

안 될 때 확인할 것

  • L은 깜빡이는데 브레드보드 LED만 안 켜져요 → LED를 거꾸로 꽂지 않았는지(긴 다리가 저항 쪽), 다리가 같은 줄에 나란히 꽂히지 않았는지 확인하세요.
  • 둘 다 안 켜져요 → 업로드가 됐는지, 코드의 핀 번호(13)와 점퍼선을 꽂은 핀이 같은지 확인하세요.
  • 전선은 맞는데 안 돼요 → 부품 다리가 구멍에 끝까지 들어갔는지, 가운데 홈을 건너 끊긴 줄에 꽂지 않았는지 보세요.
  • LED가 아주 어두워요 → ① LED 방향 ② 저항 색 띠(빨강·빨강·갈색인지, 220Ω보다 훨씬 큰 10kΩ 같은 저항을 꽂지 않았는지) ③ 저항과 LED가 같은 묶음 줄에 제대로 꽂혔는지 순서대로 확인하세요.
