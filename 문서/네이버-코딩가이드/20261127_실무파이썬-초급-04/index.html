파일마다 '어디로 갈까?' 묻기

우편물을 나누는 사람을 떠올려 보세요. 봉투를 하나 집을 때마다 차례로 묻습니다.

[[ 이미지: 차례로 묻는 분류대 (03-차례로-묻는-분류대.png) ]]

코드로 쓰면 이렇게 됩니다.

if file.is_dir():
    box = "그대로"
elif file.name == "desktop.ini":
    box = "그대로"
elif file.suffix == ".xlsx":
    box = "엑셀"
elif file.suffix == ".pdf":
    box = "PDF"
elif file.suffix in [".jpg", ".png"]:
    box = "사진"
else:
    box = "기타"

◆ 이렇게 읽으면 됩니다

• if: 만약 ~라면

• elif: 아니고, 만약 ~라면

• else: 위에 다 아니라면

 

위에서부터 차례로 묻고, 처음 맞는 한 곳만 실행합니다. 나머지는 묻지도 않고 지나가요.

for처럼 줄 끝에 쌍점(:)을 찍고, 할 일은 네 칸 들여 씁니다.

◆ 처음 보는 표시

• file.is_dir(): 폴더라면 '맞다'가 됩니다.

• desktop.ini: 윈도우가 폴더 표시에 쓰는 숨은 설정 파일이에요. 옮기면 안 되니 그대로 둡니다.

• file.suffix: 확장자입니다. 점까지 붙은 .xlsx 모양이에요.

• ==: '같다면'입니다. 등호를 두 개 씁니다.

 

등호 하나(=)는 1편의 '이름표 붙이기'예요.

in [".jpg", ".png"]는 '이 리스트 안에 있다면'입니다. 2편에서 배운 리스트를 그대로 썼어요.

2단계: 확인했으면 진짜로 옮기기

미리보기 코드에 네 줄을 더합니다. sort_files.py로 저장하고 F5를 누르세요.

from pathlib import Path

folder = Path(__file__).parent / "다운로드연습"

for file in sorted(folder.iterdir()):
    if file.is_dir():
        box = "그대로"
    elif file.name == "desktop.ini":
        box = "그대로"
    elif file.suffix == ".xlsx":
        box = "엑셀"
    elif file.suffix == ".pdf":
        box = "PDF"
    elif file.suffix in [".jpg", ".png"]:
        box = "사진"
    else:
        box = "기타"

    if box != "그대로":
        target = folder / box
        target.mkdir(exist_ok=True)
        file.rename(target / file.name)
    print(file.name, "→", box)

[[ 이미지: 실행 결과 (04-실행-결과.png) ]]

◆ 더한 네 줄

• !=: '같지 않다면'입니다. 폴더가 아닐 때만 옮겨요.

• mkdir(exist_ok=True): 2편에서 본 폴더 만들기입니다. 이미 있으면 그냥 넘어가요.

• rename(target / file.name): 3편의 그 줄입니다. 이름은 그대로, 사는 곳만 바뀝니다.

◆ 한 번 더 실행하면?

이번에는 괜찮습니다. 남은 것이 모두 폴더라서 '그대로'만 다섯 줄 나오고 끝나요.

 

3편 숙제: 날짜가 이미 붙었으면 건너뛰기

3편 rename.py의 for 부분을 이렇게 바꾸면 됩니다.

for file in sorted(folder.iterdir()):
    if file.name.startswith(stamp):
        print(file.name, "→ 건너뜀")
    else:
        new_name = f"{stamp}_{file.name}"
        file.rename(folder / new_name)
        print(new_name)

startswith(stamp)는 '오늘 날짜로 시작한다면'입니다. 이미 붙은 파일은 건드리지 않고, 나머지만 바꿔요.

 

진짜 다운로드 폴더에 쓰려면?

folder 줄만 바꾸면 됩니다.

folder = Path.home() / "Downloads"

Path.home()는 내 사용자 폴더입니다. 다운로드 위치를 따로 바꿨다면 경로가 다를 수 있어요.

바로 옮기지 말고 아래부터 지키세요.

• 받는 중인 파일이 있으면 다 받은 뒤에 실행합니다.

 

진짜 다운로드 폴더에는 숨은 파일 desktop.ini가 있습니다. 그래서 코드에 처음부터 두 줄을 넣었어요.

이 두 줄은 꼭 남겨 두세요. 빼면 desktop.ini가 '기타' 폴더로 옮겨집니다.

 

안 될 때 확인할 것

[[ 이미지: 안 될 때 (05-안-될-때.png) ]]

• SyntaxError: expected ':' — if 줄 끝에 쌍점이 빠졌어요.

• Maybe you meant '==' instead of '='? — '같다'에 등호를 하나만 썼어요.

• 오류는 없는데 엑셀이 '기타'로 감 — "xlsx"처럼 점을 빼먹었어요.

• FileExistsError: [WinError 183] — 옮길 폴더에 같은 이름 파일이 이미 있어요.

 

마지막 오류로 멈추면, 그 앞의 파일은 이미 옮겨져 있습니다. 같은 이름 파일을 정리한 뒤 다시 실행하세요.
