🤖 두이: 안녕! 지금까지는 아두이노가 혼자 불을 켰지? 오늘은 네가 버튼을 누르면 아두이노가 알아채게 할 거야!

[[ 이미지: 타이틀 (01-타이틀.png) ]]

'아두이노 기초' 연재 5편입니다. 3편에서는 브레드보드에 LED와 저항을 연결했고, 4편에서는 저항을 바꾸면 LED 밝기가 어떻게 달라지는지 알아봤어요.

지금까지 아두이노는 LED에 신호를 내보내기만 했어요. 오늘은 처음으로 바깥에서 신호를 받아들이는 일을 해 봅니다.

🧩 쉽게 이해하기 — 출력과 입력

  • 출력은 아두이노가 '말하는' 거예요. LED를 켜라고 말하는 것처럼요.
  • 입력은 아두이노가 '듣는' 거예요. 버튼이 눌렸는지 귀 기울여 듣는 거죠.
  • 한 줄 정리: 지금까지는 말하기, 오늘은 듣기!

 

이번 편에서 만들 것

버튼을 누르고 있는 동안만 LED가 켜지게 만듭니다. 손을 떼면 LED가 꺼져요.

준비물: 3편에서 만든 LED 회로 + 택트 스위치 1개 + 점퍼선 2개

 

작은 버튼 속은 어떻게 생겼을까

키트에 있는 네모난 작은 버튼을 택트 스위치라고 해요. 다리가 4개 달려 있어요.

  • 다리 4개는 두 개씩 한 쌍이에요.
  • 같은 쌍의 두 다리는 안에서 늘 이어져 있어요.
  • 버튼을 누르면 두 쌍이 서로 이어져요.
  • 손을 떼면 다시 끊겨요.

[[ 이미지: 버튼 속 (03-버튼-속.png) ]]

🧩 쉽게 이해하기 — 버튼은 두 쌍 사이의 문

  • 두 쌍 사이에 작은 문이 있다고 생각해 보세요.
  • 평소에는 문이 닫혀 있어서 전기가 못 건너가요.
  • 버튼을 누르면 문이 열려 전기가 건너가요.
  • 한 줄 정리: 선은 서로 다른 쌍에 하나씩 꽂아야 문 양쪽에 연결돼요.

💡 두이의 꿀팁: 어느 다리끼리 한 쌍인지 헷갈리지? 그럴 땐 대각선으로 마주 보는 다리 두 개를 써! 키트에 흔한 다리 4개짜리 택트 스위치는 대각선 다리가 서로 다른 쌍이거든.

 

버튼을 누르면 왜 0이 될까

버튼을 핀에 그냥 연결하면 문제가 생겨요. 버튼을 안 누를 때 핀이 전원에도, GND에도 연결되지 않거든요.

그러면 핀의 값이 하나로 정해지지 않아요. 주변의 작은 전기 잡음에 따라 1과 0을 제멋대로 오가요. 아두이노가 헷갈리는 거죠.

그래서 핀을 평소에 전원 전압 쪽으로 약하게 연결해 두는 기능을 켭니다. 이것을 풀업이라고 해요.

코드에 INPUT_PULLUP이라고 쓰면 풀업이 켜져요. 그러면 이렇게 됩니다.

  • 안 누를 때: 1 (HIGH)
  • 누를 때: 0 (LOW)

여기서 1과 0은 버튼 핀에서 읽은 전기 신호의 상태를 숫자로 나타낸 거예요.

[[ 이미지: 풀업 (04-풀업.png) ]]

🧩 쉽게 이해하기 — 용수철 달린 문

  • 용수철이 달린 문을 떠올려 보세요.
  • 용수철이 문을 늘 닫힌 쪽으로 당겨요. 풀업이 핀을 전원 쪽으로 당기는 것과 같아요. 그래서 버튼을 안 누르면 값은 1이에요.
  • 손으로 밀면 문이 열리죠. 버튼을 누르면 핀이 GND와 연결되면서 값이 0이 돼요.
  • 한 줄 정리: 풀업에서는 안 누르면 1, 누르면 0! 거꾸로 같지만 이게 맞아요.

여기서 1과 0은 '버튼을 눌렀는지'를 읽은 값이에요. LED가 켜졌는지와는 다른 이야기니 헷갈리지 마세요.

 

회로 연결하기

3편의 LED 회로는 그대로 둬요. 버튼만 더합니다. USB 케이블을 뽑고 꽂으세요.

  • ① 버튼을 브레드보드 가운데 홈에 걸쳐 꽂아요.
  • ② 보드의 2번 핀을 버튼의 한쪽 다리에 연결해요. 그 다리가 꽂힌 브레드보드 구멍과 같은 줄에 선을 꽂으면 돼요.
  • ③ 보드의 GND를 버튼의 대각선 반대쪽 다리에 같은 방법으로 연결해요.
  • 두 선은 꼭 서로 다른 쌍의 다리에 연결해요. 배선도의 빨간 동그라미 자리를 보세요.

[[ 이미지: 배선도 (05-배선도.png) ]]

우노 보드에는 GND 핀이 여러 개 있어요. 서로 연결되어 있으니 쓰기 편한 GND 핀을 골라 쓰면 돼요.

버튼에는 저항을 따로 달지 않아요. INPUT_PULLUP이 그 일을 대신해 주거든요.

 

코드 쓰기

int ledPin = 13;     // LED를 꽂은 핀
int buttonPin = 2;   // 버튼을 꽂은 핀

void setup() {
  pinMode(ledPin, OUTPUT);
  pinMode(buttonPin, INPUT_PULLUP);   // 버튼 핀을 '풀업 입력'으로
  Serial.begin(9600);
}

void loop() {
  int buttonState = digitalRead(buttonPin);   // 버튼 읽기
  Serial.println(buttonState);                // 1 또는 0 보여 주기

  if (buttonState == LOW) {      // 눌렀으면(LOW)
    digitalWrite(ledPin, HIGH);  // LED 켜기
  } else {                       // 안 눌렀으면(HIGH)
    digitalWrite(ledPin, LOW);   // LED 끄기
  }
  delay(100);   // 잠깐 기다린 뒤 다시 버튼 읽기
}
  • pinMode(buttonPin, INPUT_PULLUP); — 2번 핀을 입력('듣는 핀')으로 정하고 풀업을 켜요.
  • digitalRead(buttonPin) — 버튼 핀의 상태를 읽어요. 결과는 HIGH(1) 아니면 LOW(0)예요.
  • Serial.println(buttonState); — 읽은 값을 시리얼 모니터에 보여 줘요.
  • delay(100); — 0.1초마다 한 번씩 읽어요. 그래서 아주 빠르게 눌렀다 떼면 놓칠 수 있어요. 천천히 눌러 보세요.

if와 else는 '만약에'

코드 아래쪽의 if와 else가 오늘의 핵심이에요. 아두이노가 처음으로 스스로 고르는 부분이거든요.

🧩 쉽게 이해하기 — 우산 고르기

  • "만약 비가 오면 우산을 챙긴다. 아니면 모자를 쓴다."
  • 이 문장을 코드 모양으로 쓰면 if (비가 온다) { 우산 } else { 모자 }예요. 생김새만 흉내 낸 거라, 실제로는 아두이노가 알아듣는 말로 바꿔 써야 해요.
  • 오늘 코드도 똑같아요. "만약 버튼 값이 0이면 LED를 켠다. 아니면 끈다."
  • 한 줄 정리: if는 '만약에', else는 '아니면'!

==는 두 값이 같은지 비교하는 기호예요. 값을 넣어 두는 =(하나)와 달라요. 비교할 때는 꼭 두 개를 붙여 써요.

 

업로드하고 결과 보기

USB 케이블을 꽂고 업로드하세요. 그다음 시리얼 모니터를 열고 속도를 9600에 맞춰요.

  • 버튼을 안 누르면 1이 계속 나와요. LED는 꺼져 있어요.
  • 버튼을 누르고 있으면 0이 나와요. LED가 켜져요.
  • 손을 떼면 다시 1이 나오고 LED가 꺼져요.

안 될 때 확인할 것

  • 안 눌러도 0만 나와요 → 두 선을 같은 쌍 다리에 꽂았을 수 있어요. 대각선 다리로 다시 꽂아 보세요.
  • 눌러도 1만 나와요 → 2번 핀 선과 GND 선이 버튼의 서로 다른 쌍 다리에 각각 연결됐는지 보세요. 선과 다리가 구멍에 끝까지 들어갔는지도요.
  • 값이 제멋대로 바뀌어요 → 코드에 pinMode(buttonPin, INPUT_PULLUP);이라고 썼는지 확인하세요.

👩‍🏫 학부모·선생님께

  • 부품을 꽂거나 옮길 때는 꼭 USB 케이블을 뽑은 상태에서 하도록 지도해 주세요.
  • '누르면 0'이 헷갈리는 학생이 많습니다. 시리얼 모니터의 1과 0을 보며 버튼을 눌렀다 떼 보게 하면 이해가 빠릅니다.
  • 본문은 쉽게 줄여 썼습니다. 정확히는 이렇습니다.
    • 아무것도 연결하지 않은 입력 핀은 주변 전기 잡음 때문에 값이 제멋대로 바뀝니다(아두이노 공식 안내의 '떠 있는' 상태).
    • INPUT_PULLUP은 칩 안의 풀업 저항을 켜서 핀을 전원 전압(우노는 5V) 쪽으로 약하게 이어 두는 기능입니다. 우노 같은 대부분의 AVR 보드에서 이 저항은 20~50kΩ으로 안내되어 있습니다.
    • 13번 핀에는 보드에 붙은 LED 회로가 이어져 있어 입력으로 쓰면 예상하지 못한 영향을 받을 수 있습니다.
    • 코드의 delay(100)은 0.1초 간격으로 버튼을 읽게 합니다. 아주 빠르게 눌렀다 떼면 그 짧은 입력을 놓칠 수 있습니다.
  • 택트 스위치 다리는 쉽게 휘어집니다. 휘었다면 무리하게 펴지 말고, 다치지 않게 조심해서 바로잡거나 새 부품으로 바꿔 주세요.
