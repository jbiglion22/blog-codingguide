🤖 두이: 안녕! 지난번엔 누르는 동안만 불이 켜졌지? 오늘은 진짜 방 전등 스위치처럼 만들어 볼 거야!

[[ 이미지: 타이틀 (01-타이틀.png) ]]

'아두이노 기초' 연재 6편입니다. 5편에서는 버튼을 누르고 있는 동안만 LED를 켰어요.

그런데 방 전등 스위치는 그렇지 않죠. 한 번 누르면 켜지고, 손을 떼도 켜져 있어요. 다시 누르면 꺼지고요. 오늘은 이런 스위치를 만들어요.

 

이번 편에서 만들 것

  • 버튼을 한 번 누르면 LED가 켜져요.
  • 손을 떼도 LED는 켜진 채로 있어요.
  • 다시 한 번 누르면 LED가 꺼져요.

[[ 이미지: 이번 편에서 만들 것 (02-이번-편에서-만들-것.png) ]]

준비물: 5편에서 만든 회로 그대로 (새 부품은 없어요)

이 스위치를 만들려면 아두이노가 두 가지를 할 줄 알아야 해요. 하나씩 알아봐요.

 

첫째, 기억하기

손을 떼도 LED가 켜져 있으려면, 아두이노가 'LED가 지금 켜져 있다'는 걸 기억해야 해요.

🧩 쉽게 이해하기 — 이름표 붙은 기억 상자

  • 아두이노 안에 이름표를 붙인 작은 상자가 있다고 생각해 보세요.
  • ledState 상자에는 LED가 지금 켜져 있는지 꺼져 있는지를 기억해요.
  • lastButton 상자에는 바로 전에 읽은 버튼의 상태를 기억해요.
  • 한 줄 정리: 이런 상자를 변수라고 해요. 3편의 ledPin도 같은 상자였어요!

 

둘째, '막 누른 순간' 찾기

버튼을 누르고 있는 동안 아두이노는 버튼 상태를 아주 빠르게 여러 번 읽어요. 그래서 만약 5편처럼 '눌려 있는가'만 보고 LED를 바꾸면, 누르고 있는 동안 켰다 껐다가 계속 반복될 수 있어요.

그래서 버튼이 막 눌린 그 순간 딱 한 번만 바꿔야 해요.

🧩 쉽게 이해하기 — 교실에 들어오는 순간 세기

  • 교실에 몇 명이 들어오는지 센다고 해 봐요.
  • 문 앞에 서 있는 사람을 계속 세면 숫자가 엉망이 돼요.
  • '밖에 있다가 안으로 들어온 순간'에만 한 번 세야 해요.
  • 버튼도 같아요. 5편에서 배웠듯이 버튼을 안 누르면 1, 누르면 0이에요. 그러니 바로 전 값이 1이고 지금 값이 0이면, 그때가 막 누른 순간이에요.
  • 한 줄 정리: 바로 전 값과 지금 값이 다를 때만 살펴봐요!

[[ 이미지: 막 누른 순간 (04-막-누른-순간.png) ]]

 

회로 연결하기

회로는 5편과 똑같아요. 그대로 쓰면 돼요.

  • LED: 13번 핀 → 220Ω 저항 → LED → GND
  • 버튼: 2번 핀 → 버튼의 한쪽 다리 → 다른 쌍의 다리 → GND (대각선 다리를 쓰면 쉬워요)

[[ 이미지: 배선도 (03-배선도.png) ]]

 

코드 쓰기

int ledPin = 13;
int buttonPin = 2;
int ledState = LOW;      // 지금 LED 상태(처음엔 꺼짐)
int lastButton = HIGH;   // 바로 전에 읽은 버튼 값

void setup() {
  pinMode(ledPin, OUTPUT);
  pinMode(buttonPin, INPUT_PULLUP);
  Serial.begin(9600);
}

void loop() {
  int nowButton = digitalRead(buttonPin);

  if (nowButton != lastButton) {   // 버튼 값이 바뀌었을 때만
    if (nowButton == LOW) {        // 막 누른 순간이면
      if (ledState == LOW) {
        ledState = HIGH;
        Serial.println("LED 켜짐");
      } else {
        ledState = LOW;
        Serial.println("LED 꺼짐");
      }
      digitalWrite(ledPin, ledState);
    }
    delay(50);                     // 떨림을 건너뛰려고 잠깐 기다리기
  }
  lastButton = nowButton;          // 이번 값을 기억해 두기
}

길어 보이지만 세 덩어리로 나누면 쉬워요.

  • 맨 위: 기억 상자 두 개를 만들어요. ledState는 LED 꺼짐(LOW)으로, lastButton은 버튼 안 누른 상태(HIGH)로 시작해요.
  • 가운데: 버튼 값이 바로 전과 달라졌고(!=), 새 값이 LOW라면 막 누른 것으로 판단해요. 그때 ledState를 반대로 바꿔요. 켜져 있으면 끄고, 꺼져 있으면 켜요.
  • 맨 아래: 지금 읽은 값을 '바로 전 값' 상자에 옮겨 둬요. 다음 비교에 쓰려고요.

!=는 '다른가?' 하고 묻는 기호예요. 5편의 ==(같은가?)와 반대예요. 두 값이 다르면 '맞다(참)', 같으면 '아니다(거짓)'가 돼요.

 

delay(50)은 왜 있을까: 버튼 떨림

코드에 delay(50);이라는 줄이 있죠? 이 줄이 없으면 이상한 일이 생길 수 있어요. 한 번 눌렀는데 LED가 여러 번 바뀌는 거예요.

버튼 안에는 작은 금속 조각(접점)이 있어요. 누르는 순간 이 접점이 한 번에 딱 붙지 않고, 아주 짧게 붙었다 떨어졌다를 반복할 수 있어요. 이것을 채터링(버튼 떨림)이라고 해요.

[[ 이미지: 버튼 떨림 (05-버튼-떨림.png) ]]

🧩 쉽게 이해하기 — 통통 튀는 공

  • 공을 바닥에 떨어뜨리면 바로 멈추지 않고 통통 튀어요.
  • 버튼 속 금속 접점도 눌리는 순간 아주 작게 튀어요.
  • 사람 눈에는 한 번이지만, 아주 빠른 아두이노는 여러 번 누른 걸로 읽어요.
  • 그래서 값이 바뀐 걸 알아챈 뒤 0.05초 기다려요. 그 짧은 사이에 생기는 떨림을 줄이려는 거예요. (버튼이 꼭 0.05초 안에 멈춘다는 뜻은 아니에요.)
  • 한 줄 정리: 떨림을 건너뛰는 이 방법을 디바운스라고 해요!

[[ 이미지: 떨림 막기 전과 후 (06-떨림-막기-전후.png) ]]

그림은 떨림이 있는 버튼을 예로 든 거예요. 떨림이 얼마나 생기는지는 버튼마다 달라요.

 

업로드하고 결과 보기

USB 케이블을 꽂고 업로드한 뒤, 시리얼 모니터(속도 9600)를 열어요.

  • 버튼을 한 번 누르면 LED가 켜져요. 시리얼 모니터에 "LED 켜짐"이 나와요.
  • 손을 떼도 LED는 켜져 있어요.
  • 다시 누르면 LED가 꺼지고 "LED 꺼짐"이 나와요.

※ 회로를 바르게 연결하고 업로드했다면 이렇게 동작합니다.

💡 두이의 꿀팁: 시리얼 모니터에 한글이 깨져 보이면 "LED ON", "LED OFF"처럼 영어로 바꿔도 돼. 하는 일은 똑같아!

 

안 될 때 확인할 것

  • 눌러도 아무 변화가 없어요 → 5편 코드를 먼저 올려 버튼을 확인해 보세요. 안 누를 때 1, 누를 때 0이 나오면 버튼 쪽 회로는 괜찮아요. LED가 안 켜지면 LED 쪽 연결도 따로 살펴보세요.
  • 한 번 눌렀는데 두 번 바뀌어요 → delay(50);이 있는지 보세요. 그래도 그러면 50을 100으로 바꿔 시험해 보세요. 다만 너무 늘리면 빠르게 누르는 걸 놓칠 수 있어요.
  • 누를 때마다가 아니라 누르고 있는 동안 깜빡여요 → if (nowButton != lastButton) 줄과 맨 아래 lastButton = nowButton; 줄이 있는지 보세요.

🎯 두이의 미션

  • 켜진 채로 시작하기: 처음부터 LED가 켜져 있게 바꿔 보기 (힌트: ledState의 처음 값)

👩‍🏫 학부모·선생님께

  • 부품을 꽂거나 옮길 때는 꼭 USB 케이블을 뽑은 상태에서 하도록 지도해 주세요.
  • 이 편의 핵심은 '바로 전 값과 지금 값을 비교한다'는 생각입니다. 종이에 1, 1, 0, 0, 1을 적고 '바뀐 곳'에 동그라미를 쳐 보게 하면 이해가 빠릅니다.
  • 본문은 쉽게 줄여 썼습니다. 정확히는 이렇습니다.
    • 이 코드의 delay(50)은 아두이노 공식 예제(State Change Detection)와 같은, 학습용 간단한 디바운스입니다. 기다린 뒤 버튼 상태를 다시 확인하지는 않아서 모든 버튼의 떨림을 완벽히 없애지는 못합니다.
    • 또 lastButton = nowButton;은 50ms를 기다린 뒤에 실행되지만, 기록하는 값은 기다리기 전에 읽은 값입니다. 그래서 떨림이 50ms보다 길게 이어지는 버튼에서는 여전히 여러 번 인식될 수 있습니다.
    • 더 정확하게 하려면 일정 시간이 지난 뒤 버튼 상태를 다시 확인해, 그때도 같은 값일 때만 눌린 것으로 치는 방법을 씁니다(공식 예제 Debounce는 millis()로 시간을 재는 방식).
    • 떨림이 나타나는 정도는 버튼마다 다릅니다. delay(50)이 없어도 멀쩡해 보이는 버튼도 있고, 넣어도 가끔 두 번 바뀌는 버튼도 있을 수 있습니다.
