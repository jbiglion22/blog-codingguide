🤖 두이: 안녕! 지난번엔 저항을 끼워서 LED를 켰지? 오늘은 저항을 바꾸면 무슨 일이 생기는지 실험해 보자!

[[ 이미지: 타이틀 (01-타이틀.png) ]]

'아두이노 기초' 연재 4편입니다. 3편에서는 브레드보드에 LED와 220Ω 저항을 꽂아 불을 켰어요.

그런데 저항을 다른 것으로 바꾸면 어떻게 될까요? 오늘은 직접 바꿔 끼워 보며 그 이유를 알아봐요.

 

이번 편에서 만들 것

같은 LED에 저항만 바꿔 끼우고 밝기를 비교합니다.

  • 220Ω 저항을 끼우면 LED가 더 밝게 켜져요.
  • 1kΩ 저항을 끼우면 LED가 상대적으로 어둡게 켜져요.

[[ 이미지: 이번 편에서 만들 것 (02-이번-편에서-만들-것.png) ]]

준비물: 3편에서 만든 LED 회로 + 1kΩ 저항 1개

왜 밝기가 달라질까요? 실험 전에 전기의 세 친구부터 만나 봐요.

 

전기를 물로 생각해 보기

전기는 눈에 보이지 않아요. 그래서 물로 바꿔 생각하면 쉬워요.

[[ 이미지: 물로 보는 전기 (03-물로-보는-전기.png) ]]

🧩 쉽게 이해하기 — 높은 물탱크와 수도관

  • 전압은 물을 미는 힘이에요. 물탱크가 높을수록 물을 세게 밀어요. 단위는 V(볼트)예요.
  • 전류는 관을 지나가는 물의 양이에요. 단위는 A(암페어)예요.
  • 저항은 물의 흐름을 방해하는 정도예요. 관의 좁은 부분처럼요. 좁을수록 물이 조금 지나가요. 단위는 Ω(옴)이에요.
  • 한 줄 정리: 미는 힘은 전압, 흐르는 양은 전류, 막는 정도는 저항!

우노 핀을 HIGH로 켜면 약 5V가 나와요. 미는 힘이 5만큼이라고 생각하면 돼요.

💡 두이의 꿀팁: 전류는 아주 작은 단위인 mA(밀리암페어)를 자주 써. 1A를 1,000개로 나눈 하나가 1mA야. 1m가 1,000mm인 것과 같아!

 

LED에 전기가 얼마나 흐를까

세 친구 사이에는 규칙이 있어요. 이 규칙을 옴의 법칙이라고 해요.

🧩 쉽게 이해하기 — 나눗셈 하나면 끝

  • 규칙은 전류 = 저항에 걸리는 전압 ÷ 저항이에요.
  • 미는 힘(전압)이 크면 물이 많이 흘러요.
  • 관이 좁으면(저항이 크면) 물이 적게 흘러요.
  • 한 줄 정리: 저항에 걸리는 전압을 저항으로 나누면 전류가 나와요!

220Ω일 때 차근차근 계산하기

  • 1단계: 핀을 HIGH로 켜면 약 5V가 나와요.
  • 2단계: 빨간 LED에는 약 2V가 걸린다고 가정해요. 그러면 저항에 걸리는 전압은 5 − 2 = 3V예요.
  • 3단계: 3V를 220Ω으로 나눠요. 3 ÷ 220 ≈ 0.014A예요.
  • 4단계: 0.014A를 mA로 바꾸면 약 14mA예요.

[[ 이미지: 계산 계단 (04-계산-계단.png) ]]

우노 공식 사양에는 핀 하나에 20mA로 안내되어 있어요. 계산한 14mA는 이보다 작아요. 아두이노 공식 안내도 우노에서는 LED에 220Ω을 쓰면 된다고 설명해요.

다만 이 14mA는 계산으로 어림한 값이에요. 실제 전류는 LED와 부품에 따라 조금씩 달라요.

저항이 없으면 어떻게 될까요? 관을 좁혀 주는 부분이 없으니 물이 콸콸 쏟아지겠죠. 회로에서도 전류를 막아 줄 것이 없어져요. 전류가 너무 커지면 LED나 아두이노 핀이 망가질 수 있어요.

 

1kΩ 저항은 어떻게 찾을까: 색 띠 읽기

키트에는 저항이 여러 개 섞여 있어요. 그중 1kΩ을 찾아야 해요. 저항에는 숫자 대신 색 띠가 그려져 있어요.

[[ 이미지: 색 띠 읽기 (05-색-띠-읽기.png) ]]

🧩 쉽게 이해하기 — 색깔 암호 풀기

  • 여기서는 띠가 4개인 저항으로 설명할게요.
  • 색마다 숫자가 하나씩 정해져 있어요. 예: 검정 0, 갈색 1, 빨강 2.
  • 첫째 띠와 둘째 띠는 숫자 두 개예요.
  • 셋째 띠는 뒤에 붙일 0의 개수예요.
  • 넷째 띠는 '실제 값이 조금 다를 수 있다'는 표시(오차)예요. 금색이면 약 5% 안에서 달라질 수 있다는 뜻이라, 크기를 읽을 때는 빼고 봐도 돼요.
  • 예: 빨강(2)·빨강(2)·갈색(0 하나) → 220Ω
  • 예: 갈색(1)·검정(0)·빨강(0 두 개) → 1,000Ω = 1kΩ
  • 읽는 방향: 금색(또는 은색) 띠를 오른쪽에 두고 왼쪽부터 읽어요.
  • 한 줄 정리: 숫자 두 개 쓰고, 셋째 띠만큼 0을 붙이기!

k(킬로)는 1,000이라는 뜻이에요. 1kg이 1,000g인 것과 같아요.

 

회로 연결하기

회로는 3편과 같아요. 저항 자리만 바꿔 끼워요.

  • ① 처음에는 3편 그대로 220Ω 저항을 꽂아 둬요.
  • ② 바꿀 때는 꼭 USB 케이블을 먼저 뽑아요.
  • ③ USB가 뽑힌 상태에서 220Ω 저항을 빼고, 같은 위치에 1kΩ 저항을 꽂아요.

[[ 이미지: 배선도 (06-배선도.png) ]]

 

코드 쓰기

이번에는 LED를 계속 켜 두는 코드를 써요. 깜빡이면 밝기를 비교하기 어렵거든요.

int ledPin = 13;   // LED를 꽂은 핀

void setup() {
  pinMode(ledPin, OUTPUT);
  digitalWrite(ledPin, HIGH);   // LED를 켜 둔다
}

void loop() {
  // 할 일이 없으니 비워 둔다
}
  • LED를 켜는 일은 setup()에서 한 번만 해요.
  • loop()는 비워 둬도 괜찮아요. LED는 켜진 채로 있어요.

 

업로드하고 결과 보기

  • ① 220Ω 저항으로 업로드하고 LED 밝기를 봐요.
  • ② USB를 뽑고 1kΩ으로 바꿔 끼워요.
  • ③ USB를 다시 꽂으면 아까 업로드한 코드가 다시 실행돼요. 저항만 바꿨으니 코드는 다시 올리지 않아도 돼요.
  • ④ 두 밝기를 비교해요.

[[ 이미지: 실행 결과 (07-실행-결과.png) ]]

1kΩ으로 바꾸면 LED가 상대적으로 어두워져요. 계산해 보면 이유가 보여요.

  • 220Ω일 때: 3V ÷ 220Ω → 약 14mA
  • 1kΩ일 때: 3V ÷ 1,000Ω → 3mA

흐르는 전기가 줄어서 덜 밝아지는 거예요. 아두이노 공식 안내에도 우노에서는 1kΩ까지 LED가 보인다고 나와 있어요.

두 숫자도 LED에 2V가 걸린다고 가정한 어림값이에요. 실제 전류는 LED 종류에 따라 달라요. 그래도 같은 LED라면 저항이 클수록 전류가 줄고 덜 밝아져요.

※ 회로를 바르게 연결했다면 이렇게 됩니다. 밝기 차이는 LED와 방의 밝기에 따라 다르게 느껴질 수 있어요.

 

안 될 때 확인할 것

  • 바꿨더니 LED가 아예 안 켜져요 → 새 저항이 원래 자리와 같은 줄에 꽂혔는지, 다리가 끝까지 들어갔는지 보세요.
  • 너무 어두워서 거의 안 보여요 → 금색 띠를 오른쪽에 두고 색 띠를 다시 읽어 보세요. 갈·검·주황이면 10kΩ이에요. 1kΩ은 갈·검·빨강·금이에요.
  • 밝기 차이를 잘 모르겠어요 → 방을 조금 어둡게 하고, 두 저항을 번갈아 끼워 보세요.

👩‍🏫 학부모·선생님께

  • 저항을 바꿔 끼울 때는 꼭 USB 케이블을 뽑은 상태에서 하도록 지도해 주세요.
  • 본문은 쉽게 줄여 썼습니다. 정확히는 이렇습니다.
    • 빨간 LED가 쓰는 전압(순방향 전압)은 아두이노 공식 안내에 보통 1.8~2.2V로 나옵니다. 본문의 14mA·3mA는 2V로 가정한 이론값이고, 실제 전류는 LED와 저항에 따라 조금 다릅니다.
    • 20mA는 우노 R3 공식 사양에 I/O 핀 하나당 전류로 안내된 값입니다. 모든 조건에서 안전을 보장하는 절대 기준은 아니며, 이 값보다 넉넉히 작게 쓰는 것이 좋습니다. 멀티미터가 있다면 실제 전류를 재어 보게 해도 좋습니다.
    • 본문의 물 비유(물탱크 높이 = 전압)는 이해를 돕기 위한 단순화입니다. 실제 회로에서 저항의 핵심 역할은 전류를 제한하는 것입니다.
    • 색 띠가 5개인 저항도 있습니다. 이때는 앞의 세 띠가 숫자, 넷째 띠가 0의 개수입니다.
  • 330Ω 미션의 답은 약 9mA입니다(3 ÷ 330 ≈ 0.009A).
