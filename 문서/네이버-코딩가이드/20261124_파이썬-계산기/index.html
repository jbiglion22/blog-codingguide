그런데 마지막 줄은 3이 아니라 3.0이에요. 왜 그럴까요?

오늘은 정수 두 개를 입력해 사칙연산을 하는 계산기를 만들어 봅니다. 코드는 딱 여섯 줄이에요.

오늘 만들 프로그램

숫자 두 개를 넣으면, 컴퓨터가 네 가지 계산을 한 번에 해 줘요.

[[ 이미지: 오늘 만들 것 (03-오늘-만들-것.png) ]]

새로 배우는 건 세 가지뿐이에요.

  • input — 질문하고 답을 받아요.
  • int — 받은 답을 숫자로 바꿔요.
  • + - * / — 파이썬의 계산 기호예요.

파이썬이 아직 없다면, 맨 아래 링크한 설치 글을 먼저 보고 오세요. 오늘은 파이썬과 함께 설치되는 IDLE로 수업합니다.

 

컴퓨터가 질문하게 하기

IDLE을 열고 File → New File을 누르세요. 새 창에 첫 줄을 적어요.

a = int(input("첫 번째 수: "))

길어 보이지만 괄호 안쪽부터 읽으면 쉬워요.

 

✎ input: 질문하고 기다리기

input("첫 번째 수: ")는 화면에 "첫 번째 수:"라고 묻고, 우리가 답할 때까지 기다려요.

여기에 비밀이 하나 있어요. 우리가 12를 쳐도, 컴퓨터는 글자 '12'로 받아요.

🧩 쉽게 이해하기 — 가격표의 숫자

가게 가격표에 적힌 '1000'은 읽을 수는 있지만, 종이 두 장을 더할 수는 없죠. 계산하려면 머릿속에서 '천 원'이라는 수로 바꿔야 해요. input으로 받은 답도 아직 가격표 속 글씨 같은 상태예요.

 

✎ int: 글자를 숫자로 바꾸기

그래서 int로 감싸서 숫자로 바꿔 줍니다. int는 정수라는 뜻의 영어 integer에서 왔어요.

[[ 이미지: input과 int가 하는 일 (04-input-int.png) ]]

맨 앞의 a =는 그 숫자를 a라는 상자에 넣어 두라는 뜻이에요. 이렇게 이름표 붙은 상자를 변수라고 불러요.

두 번째 수도 똑같이 받아서 b 상자에 넣어요.

b = int(input("두 번째 수: "))

💡 파이의 꿀팁: 여는 괄호와 닫는 괄호는 개수가 같아야 해요. 줄 끝에 닫는 괄호가 두 개인 건, 안쪽 input과 바깥쪽 int를 하나씩 닫기 때문이에요.

 

계산 기호는 조금 달라요

더하기와 빼기는 수학 시간과 똑같아요. 곱하기와 나누기는 기호가 바뀝니다.

[[ 이미지: 수학 기호와 파이썬 기호 (05-수학기호-파이썬기호.png) ]]

키보드에 ×와 ÷가 없어서 별표(*)와 빗금(/)을 대신 써요. 곱하기 자리에 영어 x를 쓰면, 컴퓨터는 그냥 알파벳 x로 알아들어요.

계산한 답은 print로 보여 줘요. 쉼표 앞은 그대로 나오는 글자, 쉼표 뒤가 계산이에요.

print("더하기:", a + b)
print("빼기:", a - b)
print("곱하기:", a * b)
print("나누기:", a / b)

 

실행해 볼까요?

여섯 줄을 모으면 완성입니다.

a = int(input("첫 번째 수: "))
b = int(input("두 번째 수: "))
print("더하기:", a + b)
print("빼기:", a - b)
print("곱하기:", a * b)
print("나누기:", a / b)

File → Save로 calc.py라고 저장하고 F5를 누르세요. 질문이 나오면 정수 12를 입력하고 엔터를 누른 뒤, 정수 4를 입력하고 엔터를 칩니다.

[[ 이미지: 실행 결과 (06-실행-결과.png) ]]

 

✎ 나누기는 왜 3.0일까?

맨 처음 질문의 답이에요. 그 전에 하나 맞혀 볼까요? 7과 2를 넣으면 나누기는 뭐라고 나올까요?

정답은 3.5예요. 나누기는 이렇게 딱 떨어지지 않을 때가 많아요.

파이썬에서 / 기호로 나누면 결과는 실수(float)로 나와요. 12를 4로 나누면 3이지만, 실수 형태로 표시하기 때문에 3.0이라고 보여요.

🧩 쉽게 이해하기 — 늘 같은 모양으로 답하기

7을 2로 나누면 3.5처럼 소수점 아래 숫자가 필요하죠. 파이썬은 나누기 결과를 항상 실수 형태로 보여 주기 때문에, 딱 떨어지는 12 나누기 4도 3.0으로 표시해요.

 

일부러 틀려 보기

틀린 걸 빨리 알아보는 것도 실력이에요. 일부러 한번 틀려 봐요.

 

✎ int를 빼먹으면?

첫 두 줄에서 int를 지우고 12와 4를 넣으면, 더하기가 124로 나와요.

[[ 이미지: int를 빼먹으면 (07-int를-빼먹으면.png) ]]

글자 '12'와 글자 '4'를 옆에 이어 붙였기 때문이에요. 글자 블록 두 개를 나란히 놓은 것과 같아요.

빼기 줄에서는 빨간 글씨가 나오며 멈춥니다. 글자끼리는 뺄 수 없거든요.

TypeError: unsupported operand
type(s) for -: 'str' and 'str'

'str'은 글자라는 뜻이에요. "글자끼리는 빼기를 못 해요"라는 말이죠.

 

✎ 0으로 나누면?

두 번째 수에 0을 넣으면, 곱하기까지 잘 나오다가 나누기에서 멈춰요.

앞의 더하기, 빼기, 곱하기는 이미 계산했지만, 나누기에서 0으로 나누는 오류가 발생해 프로그램이 멈춘 거예요.

ZeroDivisionError: division by zero

"0으로 나눌 수 없어요"라는 뜻이에요. 수학에서도 0으로는 나누지 않죠. 컴퓨터도 같은 규칙을 지켜요.

 

✎ 3.5를 넣으면?

이번엔 ValueError가 나와요. 우리가 입력한 3.5는 글자 상태인 '3.5'예요. int는 이런 소수 형태의 글자를 정수로 바꾸지 못해요.

참고로 숫자 3.5 자체를 int(3.5)로 바꾸면 소수 부분을 버리고 3이 됩니다.

[[ 이미지: 오류는 쪽지 (08-오류는-쪽지.png) ]]

💡 파이의 꿀팁: 빨간 글씨는 혼나는 게 아니라 컴퓨터가 보낸 쪽지예요. 오류 메시지에는 문제가 발생한 위치와 오류의 종류, 설명이 나와요. 맨 아래쪽에 있는 오류 이름과 설명부터 읽어 보면 도움이 돼요.

 

오늘의 숙제: 사탕 나누기

사탕 17개를 친구 5명에게 똑같이 나눠 주면, 한 명에 몇 개씩이고 몇 개가 남을까요?

[[ 이미지: 몫과 나머지 (09-몫과-나머지.png) ]]

파이썬에는 이걸 바로 알려 주는 기호가 있어요. 몫은 //(빗금 두 개), 나머지는 %예요.

print("몫:", a // b)
print("나머지:", a % b)

🎯 파이의 숙제

  • 계산기 맨 아래에 위 두 줄을 더하고 17과 5를 넣어 보기. 몫: 3, 나머지: 2가 나오면 성공!
  • 질문 문장을 "사탕은 몇 개?", "친구는 몇 명?"으로 바꾸기
  • 더 해 보고 싶다면 세 번째 수 c를 받아 a + b + c 계산하기

 

여섯 줄 안에 들어 있던 것

오늘 만든 계산기는 작지만, 프로그램의 기본이 다 들어 있어요.

질문해서 받고(input), 알맞게 바꾸고(int), 계산해서(+ - * /), 보여 주기(print). 게임이나 앱도 이 순서를 아주 많이 되풀이해서 만들어져요.
