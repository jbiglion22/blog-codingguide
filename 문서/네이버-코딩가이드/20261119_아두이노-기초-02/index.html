🤖 두이: 안녕! 오늘은 드디어 코드를 써 볼 거야. 보드에 붙어 있는 작은 불빛을 내 안테나처럼 깜빡깜빡하게 만들어 보자!

[[ 이미지: 타이틀 (01-타이틀.png) ]]

'아두이노 기초' 연재 2편입니다. 지난 1편에서는 아두이노가 무엇인지, 우노 보드는 어떻게 생겼는지 알아봤어요.

이번 편에서는 아두이노 프로그램을 설치하고, 보드에 첫 코드를 넣어 내장 LED를 1초마다 깜빡이게 만들어 봅니다. 아두이노를 배우는 모든 사람이 가장 처음 해 보는, 말 그대로 첫걸음이에요.

 

이번 편에서 만들 것

보드 위 L이라고 적힌 작은 LED가 1초 켜지고, 1초 꺼지기를 계속 되풀이합니다. 그리고 컴퓨터 화면에는 아두이노가 보내는 글자가 한 줄씩 나타나요.

[[ 이미지: 이번 편에서 만들 것 (02-이번-편에서-만들-것.png) ]]

준비물: 우노 보드, USB 케이블, 컴퓨터. 이번 편은 다른 부품이 필요 없어요.

 

1단계: 아두이노 프로그램(IDE) 설치하기

아두이노에 코드를 넣으려면 컴퓨터에 아두이노 IDE라는 프로그램이 있어야 합니다. 코드를 쓰고, 검사하고, 보드로 보내는 일을 모두 이 프로그램에서 해요.

  • 내려받기: 아두이노 공식 사이트(arduino.cc)의 Software 페이지에서 '아두이노 IDE 2'를 내려받습니다.
  • 윈도우: 내려받은 설치 파일을 실행하고 안내를 따르면 됩니다. 몇 분 걸릴 수 있어요.
  • 맥: 내려받은 파일을 '응용 프로그램' 폴더로 옮기면 됩니다.
  • 필요한 컴퓨터: 윈도우 10 이상(64비트), 맥 OS 10.15 이상 등입니다. 아주 오래된 컴퓨터는 안 될 수 있어요.

[[ 이미지: 설치 순서 (03-설치-순서.png) ]]

💡 두이의 꿀팁: 학교나 공용 컴퓨터는 프로그램을 마음대로 설치할 수 없게 막혀 있을 때가 많아. 그럴 땐 선생님께 먼저 여쭤봐!

 

2단계: 보드를 연결하고 고르기

USB 케이블로 우노와 컴퓨터를 연결하고 IDE를 엽니다. 처음 보는 화면이지만, 지금은 몇 곳만 알면 돼요.

[[ 이미지: IDE 화면 읽기 (04-IDE-화면-읽기.png) ]]

  • 체크(✓) 버튼: 내 코드가 아두이노가 알아듣는 말로 바뀌는지(컴파일되는지) 확인하는 버튼입니다. 쉼표나 괄호 같은 문법 실수는 찾아 주지만, 내가 원한 대로 움직일지까지 알려 주지는 않아요.
  • 화살표(→) 버튼: 확인한 다음 보드로 코드를 보내는(업로드) 버튼입니다.
  • 보드 고르는 칸: 버튼 옆에 있어요. 연결한 보드를 여기서 고릅니다.
  • 아래 검은 창: 확인과 업로드 결과가 글자로 나오는 곳입니다.

보드 고르는 칸을 눌러 우노를 고르세요. 제대로 연결되면 보드 이름이 굵은 글씨로 보입니다. 목록에 안 보이면 'Select other board and port...'를 누르거나, 위쪽 메뉴의 Tools → Board와 Tools → Port에서 직접 고르면 돼요.

보드 패키지도 확인하기

IDE가 우노를 다루려면 우노용 '보드 패키지'가 있어야 합니다. 왼쪽 세로 막대의 보드 모양 아이콘(보드 매니저)을 눌러 'Arduino AVR Boards'를 검색해 보세요.

  • INSTALLED라고 보이면 이미 설치된 것이니 그대로 두면 됩니다.
  • 설치돼 있지 않으면 INSTALL을 누르세요. 다 되면 'INSTALLED'로 바뀝니다.

보드 패키지는 IDE 안에 넣는 '우노 사용 설명서' 같은 것이고, 컴퓨터가 보드를 알아보게 하는 USB 드라이버와는 다른 것입니다. 드라이버 이야기는 아래 '안 될 때'에서 다룰게요.

 

3단계: 첫 코드 쓰기

IDE의 빈 화면에 아래 코드를 그대로 따라 쓰세요. // 뒤의 글은 사람이 읽으라고 적은 '메모(주석)'라서, 안 써도 동작은 같아요.

// 두이의 첫 번째 코드: 내장 LED 깜빡이기
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);   // 내장 LED 핀을 '출력'으로 쓰겠다고 알려 주기
  Serial.begin(9600);             // 컴퓨터와 이야기할 준비 (속도 9600)
  Serial.println("안녕, 나는 두이야!");
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);  // 불 켜기
  Serial.println("불 켜짐");
  delay(1000);                      // 1초 기다리기
  digitalWrite(LED_BUILTIN, LOW);   // 불 끄기
  Serial.println("불 꺼짐");
  delay(1000);                      // 1초 기다리기
}

setup()과 loop(), 두 칸의 비밀

아두이노 코드는 항상 두 칸으로 나뉩니다.

  • setup(): 전원이 켜지면 딱 한 번 하는 일. 아침에 일어나서 가방을 챙기는 '준비'와 같아요.
  • loop(): 그다음부터 끝없이 되풀이하는 일. 매일 반복하는 '하루 일과'와 같아요.

[[ 이미지: setup과 loop (05-setup과-loop.png) ]]

한 줄씩 풀어 보기

  • pinMode(LED_BUILTIN, OUTPUT); — 내장 LED가 연결된 핀을 '출력'으로 쓰겠다는 약속입니다. 우노에서는 LED_BUILTIN이 13번 핀이에요.
  • Serial.begin(9600); — 컴퓨터와 글자를 주고받을 준비를 합니다. 9600은 주고받는 속도예요.
  • digitalWrite(LED_BUILTIN, HIGH); — 핀으로 HIGH(켜짐) 신호를 보내 불을 켭니다. 우노에서 HIGH는 보통 약 5V예요. LOW로 바꾸면 신호를 끄고(0V) 불이 꺼져요.
  • delay(1000); — 1000밀리초, 즉 1초 동안 기다립니다. 기다리지 않으면 너무 빨리 켜졌다 꺼져서 눈으로 볼 수 없어요.
  • Serial.println("불 켜짐"); — 컴퓨터 화면에 글자 한 줄을 보냅니다.

💡 두이의 꿀팁: 코드 줄 끝의 세미콜론(;)을 빼먹는 실수가 제일 많아! 그리고 IDE 메뉴의 File → Examples → 01.Basics → Blink 를 열면 비슷한 예제 코드를 바로 불러올 수도 있어.

 

4단계: 확인하고 업로드하기

  • 먼저 체크(✓) 버튼을 눌러 컴파일되는지 확인합니다. 문제가 없으면 아래 창에 확인이 끝났다는 글자가 나와요. 문법 실수가 있으면 빨간 글씨로 알려 줍니다.
  • 확인이 끝나면 화살표(→) 버튼을 눌러 업로드합니다.
  • 업로드가 끝나면 화면 오른쪽 아래에 알림이 뜹니다.

아두이노 공식 안내도 업로드 전에 확인부터 하는 습관을 권합니다. 틀린 곳을 미리 찾아 고칠 수 있기 때문이에요.

 

5단계: 결과 보기

업로드가 끝나면 보드의 L LED가 1초마다 켜졌다 꺼졌다 합니다. 성공이에요!

이번에는 아두이노가 보낸 글자를 볼 차례입니다. IDE 오른쪽 위의 시리얼 모니터 버튼을 누르면 아래쪽에 시리얼 모니터가 열려요. 속도를 코드와 같은 9600으로 맞추면 글자가 한 줄씩 나타납니다.

[[ 이미지: 실행 결과 (06-실행-결과.png) ]]

처음에 "안녕, 나는 두이야!"가 한 번 나오고, 그 뒤로 "불 켜짐"과 "불 꺼짐"이 1초마다 번갈아 나옵니다. setup()은 한 번, loop()는 계속 되풀이된다는 걸 눈으로 확인할 수 있죠.

💡 두이의 꿀팁: 시리얼 모니터에 한글이 이상한 기호로 깨져 보이면, 먼저 속도(9600)를 확인하고, 그래도 깨지면 따옴표 안의 글자를 영어(예: "LED ON", "LED OFF")로 바꿔 봐. 컴퓨터 환경에 따라 한글이 잘 안 보일 때가 있거든.

※ 우노를 바르게 연결하고 업로드했다면 그림처럼 동작합니다.

 

안 될 때 확인할 것

  • 컴퓨터가 보드를 못 알아봐요(목록에 아무것도 없어요) → USB 케이블이 데이터도 보내는 케이블인지 확인하고(충전 전용 케이블은 안 돼요), 다른 USB 구멍에도 꽂아 보세요. 윈도우라면 장치 관리자의 '포트(COM & LPT)'에 보드를 꽂을 때 새 항목이 생기는지 보면 컴퓨터가 알아봤는지 알 수 있어요. 호환 보드라면 판매처가 안내하는 USB 드라이버를 설치해야 할 수 있습니다.
  • 목록에는 있는데 고르기가 헷갈려요 → 'Select other board and port...'나 Tools → Board, Tools → Port에서 우노와 그 포트를 직접 고르세요.
  • 업로드하다 오류가 나요 → 보드와 포트를 다시 골라 보세요. 다른 프로그램이 보드를 쓰고 있지 않은지도 확인해요.
  • 빨간 글씨 오류가 나요 → 세미콜론(;), 괄호 ( ) { }, 따옴표(" ")를 빠뜨리지 않았는지, 대소문자가 맞는지(pinMode, digitalWrite) 확인하세요.
  • 시리얼 모니터 글자가 이상해요 → 속도를 9600으로 맞췄는지 확인하고, 한글이 깨지면 영어로 바꿔 보세요.
